# 缺少机构案卷时，公开材料能证明什么

2026-10-31。用户确认目前没有可授权的去标识化调查记录，也没有参与评审的风控分析师。本轮继续核对公开原始论文；结论限于下列已检查材料，不声称互联网上不存在合适数据。

## 同领域研究与适用边界

| 原始来源 | 已核实内容 | 本项目决定 |
|---|---|---|
| [FAA Framework，2025，IV-A/IV-C/IV-E](https://arxiv.org/html/2506.11635v1) | 欺诈告警调查与报告生成；Sparkov和CCTD均为合成数据。证据评分使用LLM；500笔分类评价包含250笔欺诈和250笔正常 | 借鉴按证据相关性、新信息、逻辑一致性和调查开销分别评估。其结果不能补足真实分析师反馈；平衡抽样指标不能直接用于我们的日终审核队列 |
| [FraudBench，2026，摘要](https://arxiv.org/abs/2608.18136) | 模拟来电者与银行Agent通过工具交互，测试身份、授权和历史相关的欺诈攻击 | 可参考状态相关权限测试。它评价银行服务Agent被欺骗后的行动安全，不是交易告警取证，当前不迁移产品主线或把它当银行调查资料 |
| [Agentic Commerce Bench，2026，摘要](https://arxiv.org/abs/2609.35886) | 研究具有支出权限的Agent遭遇交易对手欺诈；包含离线检测与对手重放框架 | 可参考不同观察范围的能力边界。当前产品没有代客支出权限，因此不为了接入该基准新增资金操作 |

我们的判断：题目名称里含有“fraud”不足以成为同一业务任务。应同时核对受保护主体、告警产生机制、可用证据、行动权限、结案来源和评测分母。合成源、模拟用户和LLM评分都可以用于研究，但不能被重新命名为独立机构验证。

## 当前可以交付的证据

- ULB/Worldline真实匿名交易：已有时间切分的检测重训对照，原数据没有可用于当前同主体历史调查的实体标识，不能与IBM拼接。
- IBM合成交易：已有检测排序到同一源交易取证、审阅和记忆的闭环；真实模型修复回归为同四案两组各4/4。这是功能验收。
- LongMemEval：已有500题的外部检索对照，检索答案字段隔离；不等于欺诈调查或人工时间收益。
- 两批真实模型原始失败、修复、费用与版本指纹已保留。便携核验脚本检查11份文件的完整性、逐案到分组的数字一致性及实验局限声明；完整源事实重算仍依赖本机原始材料。

## 下一步的准入规则

新增公开任务必须先有可核对的发布主体与使用条件、真实/合成来源说明、任务时点可得证据、与现有开发案例的重叠检查，以及独立于Agent输出的评分依据。先冻结范围和比较方案，再运行；已经观察的数据不能重称未见留出。

产品的业务价值验收继续保留：相同告警与事实权限下，对比确定性核查、简单模型方案、动态Agent；分别报告可核对结论、错误关闭、补证质量、修改量、审核时间及模型费用。没有真实人审时，审核时间和业务收益保持“未验证”，不让另一个LLM模拟人审后填补。

当前完成的是可复核的研究工程交付。把它放入简历时，应描述实现、失败驱动修复和真实实验边界；不能写“已在银行上线”“提高欺诈准确率”或“节省分析师时间”。整体业务收益目标仍未完成，本轮没有新增模型调用。
