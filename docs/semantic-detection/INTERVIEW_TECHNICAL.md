# 研究技术说明与面试边界

本页解释实现与研究判断。正式数值以RESULTS.md和results.json及独立回执为准，不用先导replacement批次充作PRD成绩。

## 为什么MCC可以具有语义表示

MCC是类别而非可测量的连续大小；经来源核验后，类别说明能表达经营类型。预训练编码器可将这种一般知识转成固定向量，供检测器学习其与训练标签的关系。它不查询具体商户，不提供真实经营状态，也不输出欺诈标签。

本研究只用MCC释义及明确渠道，不输入商户数字ID、客户资料、金额或调查记忆。词典中有冲突时回退unknown，并保留原类别码分支。这样未知释义不会抹掉可训练类别身份。

## 与普通Embedding的区别

普通可训练表从随机向量开始，只根据训练期监督梯度学习；冻结Qwen表包含外部文本预训练信息，训练期间不更新。额外投影允许检测器适配该固定空间，仍不微调大模型。

正式B1/B2使用相同数值、相同原类别分支和32维附加空间；B3增加投影，因此另设参数相同的向量对应打乱控制。只有比较支持时才能讨论语义额外收益。即使B2更好，冻结带来的正则化等因素也需谨慎区分；不能由模型名称证明金融推理能力。

B0是本轮同渠道信息的普通基线；旧冻结残差和强树另列。旧模型不输入渠道，因此旧模型比较同时涉及输入视图差异，不能当作单因素归因。

## 怎么判断LLM是否有效

固定训练期、数值输入、5轮和42/43/44三个种子；评价2018每日10名的捕获及AP，保留所有种子，并比较新增、挤出和配对日重采样区间。B3还需与shuffled比较。数据已观察、区间未作多重比较调整，结果属于开发研究，不能推广为真实未来收益。

首轮实现曾错误地替换类别表示，已单独保留并纠正为附加特征。这是设计失败记录，不能隐藏，也不能将其与正式结果混合选优。

## 历史结构能增加什么

统计窗口压缩了事件顺序；前K笔可观察交易还可保留局部金额、类别、频次等变化关系。轻量历史注意力按目标与过去节点表示分配权重，并通过门控混合自身信息；异常交易可能被正常历史稀释，图不保证有益。

目前代码有严格过去邻域及单跳时间注意力原语，不是论文四层TGAT的完整复现。图效果须以实际E2为准；未执行E2就不能声称发现了图增益。只有共享MCC，不构造真实团伙或实体边。

## 半监督怎样利用无标签样本

从2016–2017内部冻结分层mask。未暴露标签用-1表示，只在无标签集合上比较同一样本的两个独立Dropout视图。对称Bernoulli KL要求预测对这种合法模型扰动相对稳定。

监督项提供类别区分，一致性项提供稳定性约束。它没有创造新真值，也不证明隐藏交易属于正常；过强一致性可能抹平少数类信号或导致塌缩。100%标签下无无标签样本，CB-Focal与其“一致性”条件应产生相同分数，这也是独立审计的负对照。

BCE、Focal、类均衡Focal有不同加权和梯度尺度，固定学习率下结果不一定同向。类均衡权重只从已暴露训练标签的全局计数计算，不能从隐藏真值或每个批次临时计算。初版不使用标签平滑与温度锐化，不声称逐式复现论文。

E3每条件固定2轮，是资源有界的短预算研究；负结果不能证明更充分训练也无效，正结果也不是新独立时间泛化证据。

## 防泄漏与可信重放

- 模型Frame字段精确白名单，ID、时间分区、标签及Agent记忆不进入神经输入。
- 预处理和类别缓存只依据训练；2018只评分，2019不选取记录。
- 训练图拒绝非训练分段与2018及以后的日期；用户-卡必须联合且非缺失。历史邻居严格小于目标时间，同刻成组处理。
- 数据与模型哈希、文本和tokenizer版本、训练mask、全部曲线与分数保存；模型重载检验，日名单用独立SQLite或已有heap实现交叉核验。
- 合成数据缺少完整入库和标签确认时间；2026词典与预训练知识晚于交易。不能说已完整复现2016线上可用信息，也不能完全排除预训练语料污染。

## 为什么可以决定不升级

检测器的额外依赖、编码器缓存、冷启动、推理和维护成本需要实际收益支持。负结果、区间跨0、相对强树/原残差没有优势，都支持保留原默认，继续把新模型列为研究challenger。

可选告警适配器保留六个队列核心字段，模型来源单存，重新加载三seed对全量开发记录复算后导出。通用调查演示的数字通过源SQL核对；这不证明专用欺诈MCP已经支持新模型。该合同目前硬编码旧ID，必须独立集成变更，不能冒用旧ID绕过检查。

研究交付的价值在于可复核的比较、明确的失败与可替换上游；没有真实损失、用户效率和外部验证，不能换算成机构节省金额或人时。
