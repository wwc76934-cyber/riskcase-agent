## 字段与能力映射

| 字段 | 可以支持 | 不应推断 |
|---|---|---|
| User、Card | 稳定键待验证后做用户/卡历史查询 | 现实身份或完整客户画像 |
| Year/Month/Day/Time | 事件排序、历史窗口、按时间切分 | 真实标签确认时间或实时处理延迟 |
| Amount | 归一化后做金额、窗口及异常分析 | 自动认定币种、损失或回收金额 |
| Merchant Name、城市/州/Zip/MCC | 商户/类别分群与历史行为；键稳定性待验证 | 设备、IP、团伙资金流边 |
| Use Chip、Errors? | 渠道/错误模式，需字典和时点核查 | 所有字段均在授权判断之前可得 |
| Is Fraud? | 离线标签评测 | 调查工具可直接读取的事前事实 |

数据没有证明提供真实设备关系、征信、投诉、舆情或保险信息；不为凑四个系统虚构这些数据。

## 对其他候选的核查

Fraud Detection Handbook 的模拟器明确提供 customer/terminal/time/amount/label，适合可控任务金标准；但其代码 LICENSE 为 GPLv3，不能不看许可直接复制进项目。数据仓库只见 pickle 形式，未直接反序列化，也未认定数据授权与代码授权相同。可学习模式，不复制生成器。

IEEE-CIS 是真实匿名竞赛数据候选，需要接受数据使用规则并确认可获得性；本轮未登录或下载。匿名字段对调查解释的限制仍需检查。不能把它当成已经解决的第二数据源。

完整产品目标要求另核验一个真实匿名源能支持的任务。若无法获得，将显式提交范围取舍；不会只用 IBM 合成数据就宣称已验证现实欺诈调查效果。
