# 40案作者复审后的处理方案

本方案源于V31_AI_REVIEW.md的逐案发现，是开发建议，不是独立业务审查回执。当前v4及旧实验保持只读；AI作者复审不能满足原PRD要求的独立人员审查。没有独立审查时，后续结果只能称作者审阅的模拟工程实验。

## 先界定产品决策

任务是支付欺诈告警调查中的证据整理、矛盾消解与下一步调查建议。客户认可/否认是来源中的声明状态，不是实际授权、欺诈真相、退款资格或法律责任。报告必须把这些层次分开，金融处理由有权限的人员决定。

候选系统需回答：当前哪些事实有支持、哪些矛盾尚未消解、下一步取什么资料、为何值得付出成本、何时应停止或重新调查。不能以不断调用工具代替取得业务进展。

## 新版本必须具备的可执行机制

1. 时间推进由环境记录。原件的生成、可获取、失效和取得时间分别建模；尚未收到的回访结果不能作为客户原件读取。一次查询返回等待、不可得或超时状态时，不得虚构本人声明。相同时间与权限规则约束所有比较组。
2. 来源角色分开：本人陈述、转述工单、身份核验事件、设备观察、联络状态、规程元数据。认证成功只证明对应认证事件，不自动证明付款获授权；渠道登记也不自动等于本人身份核验。
3. 时间点参考分别冻结。记录必需事实、反证、尚不可确认事项及允许的建议组合。后到更正不得回填旧状态。对确有多种合理解释的原文允许集合式参考或标记争议，不强迫单一标签。
4. 停止与升级按案件定义。补件不可得、关键矛盾未消解、风险控制需要及时人工判断等条件应分别评分；不能用全案相同的宽泛动作列表证明业务建议正确。

## 场景与比较方式

|场景|业务问题|环境约束|需要验证的增量|
|---|---|---|---|
|连续证据更新|客户更正范围、订单关联和核验材料先后到达|同一案件保留调查状态；新证据触发计划修订，旧判断留痕|B4能否较B0改善语义质量；B2是否减少无效重查|
|冲突来源核实|客户、客服转述、认证与订单资料不一致|需要区分角色、目标交易和支持程度；允许事实持续未知|语言分析是否改善归属、反证和安全停止，不把未知一律判错|
|有限成本调查|多个可查来源，实际延迟、失败或资料依赖不同|每次获取计费/计时；何时可得与返回状态由环境确定|B2相对强B1/B4是否用更少成本取得同等或更好业务结果|

动态选择的价值来自可观察的新信息改变后续选择，而不是人为规定必须绕行某工具。资料没有额外成本或权限限制时，B1可取得全部当前可得资料。资料有实际成本时，各组遵守同一获取规则；B1的批量获取策略须预先声明，不能故意塞入无关材料或隐去其有权取得的关键证据。

强B0应允许明确的状态机、规则、缓存、查询优先级和预算策略。B4使用相同确定性获取策略并加入语言分析。不能以“固定代码无法覆盖”为数据设计目标；应测量实现复杂度、业务质量与资源的实际取舍。B0或B4胜出时按结果选择。

## 版本与研究纪律

- 原40案已由开发者阅读并提出修改意见，不能再称未见盲测。保留为已观察的候选/回归材料；新数据另建版本和指纹，逐项记录继承与新创作来源。
- 先用开发案验证环境和评分。不得把新评分套回旧90案、旧V3或当前V3.1后宣称提升。
- 正式样本量、配对指标、重复次数及区间方法在运行前确定；按家族报告，所有失败纳入分母。模型可靠性未达开发门槛前，不启动正式五组或记忆实验。
- AI可检查内部一致性，但不能签署独立人员身份。用户选择AI作者审阅路线时，应明确它减少的是外部有效性证据，而不是替代了独立业务真值。
- 人工减负、真实欺诈效果和生产适用性仅在实际测量后报告。当前不提出启用动态Agent的建议。
