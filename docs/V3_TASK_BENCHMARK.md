## 业务合同

任务是对支付欺诈告警进行取证，判断**目标支付的客户原话究竟确认、否认还是仍不明确**，保留反证、缺口、后续调查与人工审阅。认证成功不等于客户授权，客户说法不等于已确认欺诈；系统不能自动退款、冻结账户或作法律责任判断。

- A：T0/T1/T2逐步到件。同一时点所有方案遵守同一可访问来源表；未来资料不出现在目录中。更正原件保留旧版本及替代关系，不能覆盖历史。
- B：转述、否定范围、多支付指代、部分授权、代表身份、撤回时间、条件委托等自由文本。每个案件有独立主体及原件；没有改写旧90案后称新案。
- C：15案有获取成本或时间限制。需要先读取账户路由，再选择两个同价、同时到件的渠道之一。两个渠道总成本超过案级预算；目录顺序经哈希排序，不能靠版本或固定位置猜答案。预算和阶段窗口由宿主强制执行。

所有告警、交易、原件均明确为完全作者模拟，**不是IBM交易投影、银行记录或训练检测器输出**。真实检测模型接入仍需后续共享来源合同集成。

查询成本使用模拟配额单位，时效使用模拟调查窗口；并非银行实际收费或人工工时测量。独立审阅需检查这些限制是否业务合理，不能只保留有利于Agent的预算点。
