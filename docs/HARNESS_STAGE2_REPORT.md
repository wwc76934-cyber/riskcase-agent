## Skill 的实现及边界

项目目录 `investigation_skills/` 包含三个标准 `SKILL.md` 包：`alert-investigation`、`merchant-change`、`evidence-conflict`。描述分别说明适用场景；重复授权的优先级细节位于按需读取的参考文件。

宿主在提交时冻结技能文件及内容指纹；模型上下文初始只看名称、描述和版本。`load_skill` 才加载正文，`read_skill_resource` 才加载对应参考材料。宿主冻结文件不等于把所有正文发给模型。队列中的旧任务使用旧快照，新任务才读取新版本。

技能不可增加工具权限：工具列表仍由宿主定义，未知技能、越界资源路径以及 `shell` 等未授权工具拒绝。当前加载器接受受限的字符串 YAML 前置信息，并不实现任意第三方技能包执行。三个包已用 skill-creator 的 `quick_validate.py` 检查通过；该检查只说明格式有效，不证明效果。

参考：[Agent Skills 格式与渐进披露规范](https://agentskills.io/specification)。创建时采用了 [skill-creator](C:/Users/18137/.codex/skills/.system/skill-creator/SKILL.md) 的作用范围及按需披露原则。

## Harness 如何恢复

`HarnessStore` 继承已有 `JobStore`，复用租约、代次 fencing、取消、截止时间和模型响应日志。新调查队列使用同一套实现的独立 SQLite 文件，避免原工作流和新调查误认彼此任务；原后台 `Worker.step()` 同时处理这条队列。

新增检查点保存目标对应的任务快照、阶段、交互轮次、工具尝试、已激活技能、临时假设、待办、未知项、完整取证结果、证据编号以及待执行工具批次和游标。所有更新都检查持有者及租约代次；旧 worker 不能覆盖新 worker。

| 中断位置 | 恢复语义 |
|---|---|
| 模型响应已入日志、调查状态尚未更新 | 按相同请求哈希复用响应，不再次调用客户端 |
| 模型请求发出后结果不明 | 标记阻塞，不盲目重试 |
| 只读工具已返回、结果尚未进入检查点 | 可以重读；先前尝试已预记，重读再次计入预算 |
| 工具结果与游标已保存 | 从下一工具继续，保留证据编号 |
| 代码或冻结输入发生变化 | 拒绝恢复，不能混用执行版本 |

持续无增量的重复调用会阻塞；六次交互和十二次工具尝试跨恢复累计。新路径仍是最多180秒的受限调查，不冒称已验证小时级长任务或通用后台自治。

## 上下文管理

每轮从结构化状态构建上下文，而不是无限拼接历史对话。事实字段、来源、证据编号、覆盖标志、临时计划与未知项保留；长正文生成明确标记的截断视图，完整原文保存在检查点中，`read_evidence` 可请求重新展开。不能把“缺资料”压缩成“资料完整”。

上下文有字节上限，超限停止，不静默删除关键事实。这是可审计的结构化视图，不是学习式摘要或长期经验记忆。旧原文在证据和响应日志中保留，但不会全部自动进入每轮模型上下文。Skill 正文及主动展开的资料同样受上下文上限约束。

## 审批与副作用

草稿包含案件、验证后报告哈希、结构结论、具体工单文字及固定模拟目的地。批准绑定整份草稿哈希；保存修改会清除批准，浏览器中未保存的编辑也会禁用批准和提交按钮。

提交前在事务中保存 outbox 意图。模拟目的地另用 SQLite 并对幂等键建立唯一约束。响应丢失后，下一次操作先按持久化键查询目的地；已有工单则核对内容并复用。提交已开始时草稿锁定，避免拿旧批准提交新内容。

这证明的是本地模拟目的地支持幂等与查询时的恢复合同，不是任意外部系统的 exactly-once 保证。未来接入不支持查询/幂等的目的地时，应保留不确定状态并交给人工处理。

## 实测故障与修复

首次独立恢复演示在第二轮响应已保存后退出进程，重启时被 `replay_request_changed` 阻塞。原因是检查点规范化 JSON 改变了字典插入顺序，嵌入请求字符串中的 JSON 顺序随之改变。系统未重复请求，但无法正确恢复。

已将上下文内嵌 JSON 及已加载技能顺序规范化，并把退出测试从首轮推进到第二轮。原始失败在 `runs/harness-stage2-recovery/` 保留，修复后回执另存 `runs/harness-stage2-recovery-final/`。进程确实以23退出；租约到期由测试修改到期时间模拟，未冒称等待了90秒。

另一个测试发现 AnyIO 的清理阶段会把停止信号包在异常组里，导致重复无进展被误分类为普通失败；已对单一原因的异常组解包，保留原来的阻塞、取消和租约丢失语义。
