## 如何检查“账算对了”

- 自建小样本检查边界、当前交易、同刻交易、未来交易、不同用户、负金额、没有历史等情况。
- 从固定合成源训练特征中抽 22 笔，用 SQL 独立重新计算，核对 198 个结果，全部一致。
- 新增 14 个计算测试，全仓 126 个通过。这不代表检测准确率；目前尚未训练检测模型。抽样和小样本测试不等于穷尽证明。

## 下一步

开始规则基线，再比较逻辑回归和一个树模型。训练时把训练特征与训练标签按交易 ID 对齐；调查 Agent 始终不读取目标欺诈标签。

验证期用于选模型/阈值，测试期留作冻结方案后的最终评测。填未知值、类别编码等需要学习参数的处理只能在训练期拟合。先前已发生的验证/测试交易可以成为后来交易的历史，但它们的标签不能提前成为线索。

仍是合成数据、按事件时间的回顾性实验。标签确认时间和入库时间未知，不能宣称真实线上效果。
