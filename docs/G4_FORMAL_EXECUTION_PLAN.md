# Gate 4 正式对照执行准备

冻结计划保持 40 案、10 个家族、3 次配对重复和 B0、B1、B4、B2 四组。B0 在每案只跑一次并确定性复用。主指标是三阶段严格通过，比较 B4−B0、B2−B4、B2−B1。完整计划分母包括失败与未运行条件，家族配对区间只在对应条件的记录齐全时出具。评测为 AI 作者审阅的模拟研究。

模型组共同使用 Qwen/Qwen3.8-27B、等价严格 Schema、温度 0.2、90 秒等待、最多 2,048 个输出 Token、64,000 字节请求上限。B1 优先获取全部当前可得资料。预算不足时允许一次模型选源，并保留综合报告的一次协议修复。B2 每阶段最多四次规划请求，另外保留两次交付请求。工具权限、来源范围、时点和费用约束来自同一冻结案卷。

40 案的脚本测量覆盖三组共 120 条轨迹和 890 次离线请求，全部低于 64,000 字节。B1 刻意先生成一份带 8,192 字节填充字段的非法结果，测量有界修复后的传输尺寸。B1 最大 44,204 字节，B4 最大 26,289 字节，B2 最大 26,483 字节。实测值是给定脚本路径的观察值。真实模型请求仍须逐条执行共同上限，防止临时改写工作流或让某组独自获得更高额度。

按每次 68,096 输入 Token 代理上限和 2,048 输出 Token 估算，单次费用保守边界为 0.228864 元。所有请求达到上限时，正常用量边界 906.301440 元，加一次未知费用保护为 906.801440 元。正常实际费用应由用量回执结算。该上界不能视为实际支出预测。

预算控制优先采用固定调度和实际结算的分段批准。在授权范围、可用余额和预留足以覆盖下一条完整轨迹时才能启动。遇未知执行即停止，保留原案与费用，再审查未开始的调度。任何追加批次必须保持原样本、分组、顺序、合同、评分和冻结代码；已经启动的失败槽位保留在分母。分段运行在配对齐全前只报告进度、失败和实际费用。正式运行器已实现独占槽位、结果指纹和启动前预算核对。本机 MCP 和模拟 HTTP 已验证固定槽位、独立授权续跑及 401 后禁止跨越未知槽位。

本机回执位于 `runs/gate4-formal-wire-audit-v1`。生成上界的 `formal_envelope` 只读取冻结计划和离线测量，不加载凭据或发出模型请求。正式首段已获独立授权，B1 T1 未知执行触发停机。见 [首段结果](G4_FORMAL_TRANCHE_001.md)。
