## 用一个例子理解修复

程序要接的是一张固定表格，模型却把表格夹在一封说明信中。我们可以请它把同一份答案按表格重新交一次，但不能为了接收这封信，就取消数字和来源检查。

现在只有最终回答无法解析为严格 JSON 时，才允许一次格式纠正。纠正请求明确要求只交 JSON，不调用工具，不添加新证据；返回后重新执行完整的证据校验。

如果原回答已是合法 JSON，但引用不存在、结论不符合事实，直接拒绝，不启用格式纠正。纠正后仍不合要求，也停止。最初回答、纠正请求和纠正结果都保留在 trace 中。

这额外一次仍计入原来的最多 6 次请求、运行截止检查和费用估算账本。原请求若已用完预算，就不再纠正。HTTP 错误和未知响应依然不自动重试。这是一次模型输出格式纠正，不是无限次重新调用接口。
