## 原产品目标（历史记录）

面向支付风险分析师的多来源证据调查 Agent：根据交易、商户资料、版本化规程和历史处置记录逐步取证，处理矛盾与缺失，提交可核对结论和待审批工单。模型选择行动，宿主控制权限、预算、事实计算和完成验证。现有固定流程继续作为基线。

现有工程基础复用：只读事实投影、证据引用、预算账本、任务租约和响应日志。自建业务资料明确标识为合成材料。没有真实机构验证前不宣称生产收益。

## 阶段及门槛

1. **多来源调查主线（本阶段已验收）**：12个分支开发案例；官方 SDK 的两个独立 MCP stdio 服务；统一工具注册与治理；最小调查 Agent。验收跨来源完整调查、证据变化导致行动变化、权限及失败检查、原文/轨迹/评分保存。真实模型结果与脚本测试分开。
2. **Skill 与 Harness（本阶段已验收）**：三个按需加载并固定版本的调查 Skill；结构化调查状态、检查点、上下文管理；模拟工单草稿/审批/提交。验收中断恢复、审批绑定内容、无重复提交。Skill 不能赋予权限。
3. **RAG 与经验迭代（本阶段已验收）**：版本语料、词法/混合检索/重排对照；工作记忆与经验记忆隔离；候选修订、任务回归、审阅、发布及回滚。不能将检索命中等同于任务质量或自进化。
4. **评测与面试交付（已完成，模型收益尚未证明）**：60个场景规格按家族划分开发/回归/冻结组；固定工作流、基础 Agent、完整系统及消融；故障注入、成本与质量；演示和设计取舍。手写合成题不是外部独立测试。
5. **原始案卷与价值验证（工程及限定演示验收完成）**：原文阅读/支付引用关联、适用规程、完整台账引用、逐项语义审阅及独立案卷入口。V4两条真实模型路径各6/6，限已观察六案回归；动态少读50%原件但成本约2.89倍，小案卷默认简单路径。生产收益及独立泛化未验证，详见 [第五阶段报告](STAGE5_REPORT.md)。

每阶段完成后才报告阶段结论。阶段一不提前宣称 Skill、长任务恢复、远程授权或记忆增益已完成。不得为追求通过率修改已运行实验的原始证据。

## 能力合同

- MCP：使用官方 SDK、版本锁定、真实进程间 initialize/list/call；远程 HTTP 与企业认证在需要时实现，不能拿本地 stdio 冒充。
- 工具治理：可信宿主绑定案件/截止时间；输入输出 schema、允许列表、尝试预算、超时、结果上限、证据来源及审计。只读和写入有不同重试合同。
- Harness：显式目标/事实/假设/矛盾/待办/预算/审批状态；可恢复、可观察、可验证。运行 Harness 和评测 Harness 分离。
- 评测：任务结果、证据支持、缺失处理、越权、恢复、副作用、成本延迟分别计分；允许多条有效调查路径；不拿测试数证明 Agent 智能。
- 深度学习：保留预警排序职责，后续公平比较强表格与序列方法；已观察2019不能重新包装为未见测试。模型分数不是欺诈结论。
