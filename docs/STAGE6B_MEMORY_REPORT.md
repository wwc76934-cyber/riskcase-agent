## 记忆落在业务哪里

已完成的源事实核查和明确审阅可以生成候选，保存行为线索、未解决证据、后续核查重点和源报告指纹。候选经过来源重算和内容绑定审阅后才能发布。发布、更新、重复不操作、撤下均写审计；同一目标的新修订替代旧修订，失效后不自动回落旧版。

任务提交时先按源事实版本+主体、事件截止、实际审阅可得时间、过期状态和源批准有效性过滤，最多冻结3条记录。相同来源名称与数字用户ID不代表跨数据版本仍是同一主体，范围键因此包含源事实SHA-256。检索是宿主的只读工具，模型不能选择其他用户ID、写记忆或获得新权限。记忆条目是M引用，当前事实仍必须通过E工具重新读取。旧记录不能成为欺诈认定、授权确认或训练标签。

事件时间沿用源交易的未知时区本地时间；记忆可得时间为真实审阅UTC时间。没有把2026年的审阅记录伪装成2018年已经知道的历史。

存储复用SQLite与任务库：候选内容不可原地改写；版本记录保存变更及前版本指纹，当前有效记录单独索引。避免每次发布复制全部历史列表。先按主体/时间查询候选窗口（最多100），再校验最多3条可用记录。该上限和索引是工程约束，不是已证明生产吞吐。

撤下影响未来任务；已冻结任务与审计历史保留。它不是隐私物理擦除机制。当前只有本机令牌操作者，没有企业租户体系或独立审核员身份认证；内容指纹检测变更，不是防恶意数据库管理员的数字签名。

反思部分仍是受控的核查重点建议，不会自动生成新欺诈规则、更新模型权重或宣称已学到因果规律。30天是本研究版本的审阅上下文有效期，不是根据遗忘曲线推导的金融保留期限。

## 独立公共检索评测

使用作者发布并固定SHA-256的完整LongMemEval-S清洗版500题：470可回答、30不可回答。Runtime字段白名单剥离答案、题型、问题ID、答案会话ID及`has_answer`。每个问题只检索自己的会话，未来会话先过滤。

| 指标（470道可回答题） | 最近会话基线 | 项目BM25 |
|---|---:|---:|
| session-recall@1 | 2.94% | 53.77% |
| session-recall@3 | 8.24% | 80.84% |
| session-recall@5 | 15.36% | 85.30% |
| 完整证据会话覆盖@5 | 6.38% | 75.32% |
| MRR（最多5条） | 0.1110 | 0.8694 |

这不是答案准确率。BM25在时序题的完整覆盖@5只有50.39%，跨会话题63.64%。30道不可回答题两种方法都返回非空结果，不能把“检索有结果”当作可回答性。BM25返回上下文中位数64515字符，超过产品30000字节上下文上限，不能原样塞给产品模型。

公开数据也有格式陷阱：13题包含同ID的不同日期实例，首次运行第4题停止。保存初始协议/代码/失败，在不查看汇总成绩的情况下做实例级日期过滤、排序后按逻辑ID去重，不删除题目、不用答案挑实例。之后全部500题完成，0模型请求；没有官方LLM judge分数。

本轮公共基准暴露的是通用检索限制，不是欺诈业务提升。欺诈记忆目前使用结构化主体/时间/目标筛选，小规模下不额外部署向量库。协议：[LONGMEMEVAL_RETRIEVAL_PROTOCOL](LONGMEMEVAL_RETRIEVAL_PROTOCOL.md)。汇总与失败：[证据包](evidence/memory-public-v2/manifest.json)。
