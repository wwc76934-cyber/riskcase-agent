# 独立人员审查待办

这份任务不能由作者再次自评、机械检查或另一个自动模型代替。非专家也可以审查语言逻辑，但应如实记录知识背景，不能称外部专家真值。

审查对象：`runs/v3-author-candidates-v3`的40个evaluation候选案。每案先看runtime原件，再看controller逐阶段参考；这些参考仅供评审，不能给受测模型。数据指纹见[V3候选集说明](V3_TASK_BENCHMARK.md)。

逐案确认：

1. T0/T1/T2允许取得的资料及客户纠正是否符合业务逻辑，是否存在未来信息泄漏。
2. 目标支付与其他支付的指代是否清楚；否定、转述、部分授权的参考是否过度推断；未知是否被错误当成否认。
3. 必要反证与缺口是否完整；认证、客户说法与已确认欺诈是否区分。
4. 取证费用、前置依赖及窗口是否合理；B0/B1/B4/B2是否享有相同机会；是否可通过目录位置或元数据猜测答案。
5. 建议、禁止动作、停止及重开条件是否与当时证据匹配。

记录评审者、日期、知识背景、是否参与出题，以及每案接受/需修订/无法判断和理由。修订必须形成新版本与指纹，保留当前候选。正式评测前再冻结参考和评分协议；未经审查不填写“已独立审查”。目前本项未满足。
