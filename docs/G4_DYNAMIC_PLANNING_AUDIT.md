专项使用两个不属于正式 40 案的开发场景，案件与主体均已与冻结正式集核对。A 中主回呼可用，主回呼陈述可能混淆预授权和独立扣款。商户记录依赖主回呼原件，取得原件后才可查。B 中主回呼不可得，应用内核验原件提供替代路径。不可得是本机 MCP 返回的模拟业务状态。
