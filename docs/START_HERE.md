## 从一个告警讲起

分析师每天审核10笔交易。冻结检测模型产生日终名单，每条告警保留交易ID、源数据和模型版本。确定性工具负责历史统计，扩展研究环境再提供认证、设备、账户、客户声明、商户和规程原件。认证日志成功不能直接证明持卡人真实授权；客户否认、后续更正、来源覆盖或规程版本，需要分别核对。

模型可以选择资料、提出假设和补证建议；宿主负责案件范围、时间、来源校验及预算。最终报告需人工逐项审阅，内容绑定批准后才能提交本地模拟队列。受审阅方法来自真实开发失败的作者事实反馈和来源重验，指导后续调查，不把旧案件事实转成本案证据；撤下影响未来任务，已冻结任务保留审计快照。

## 怎样运行和检查

核对**本轮300个正式条件记录**（标准库、无需密钥）：

```powershell
python scripts/verify_agent_value_evidence.py
```

[便携包](evidence/agent-value-v1/README.md)包含预算失败及零请求条件；范围仅为哈希与汇总一致性，不认证供应商、未上传原件或全部自然语言语义。


核对**此前四案接线实验**的便携证据（Python 3.10+标准库，无需API密钥、依赖安装或原始交易）：

```powershell
python scripts/verify_fraud_live_evidence.py
```

核对11份文件指纹、16次运行的汇总一致性与两批费用；输出明确保留首次失败。它不是提供商签名认证，不重算未上传的原始事实，也不证明业务收益。已核对的公开调查研究与后续数据准入见[公开材料可行性评审](PUBLIC_INVESTIGATION_FEASIBILITY.md)。

- **本机已有IBM源数据和冻结演示包**：按[主线运行指南](FRAUD_WORKBENCH_QUICKSTART.md)准备新的欺诈调查目录，再启动工作台。主线页面是 `/investigations/page`。演示默认确定性客户端、真实MCP、零模型费用；完整记忆发布和撤下步骤也在该指南中。
- **从干净检出开始**：按[公开评测指南](PUBLIC_EVAL_QUICKSTART.md)下载固定来源并复现检测和检索实验。这条路径不依赖本机IBM权重或模型API密钥。Git中只有代码与汇总证据，原始数据、权重和运行数据库需要另行准备。
- **重建完整欺诈演示来源**：按[IBM源重建指南](FRAUD_REBUILD_GUIDE.md)从固定归档盘点、构建特征、训练到生成告警调查包；显式传递新目录。本轮验证了重建特征及训练输入，未重新验收一台全新机器的完整安装和训练。
- **准备真实模型功能验收**：按[功能验收协议](FRAUD_LIVE_ACCEPTANCE_PROTOCOL.md)区分准备与发送。普通离线工作台不会领取live任务；发送需明确的本批授权并受批次和项目总账本约束。首次真实运行及同四案修复回归均已完成，见[真实模型验收报告](FRAUD_LIVE_ACCEPTANCE_REPORT.md)；原始失败单列，不把模拟回执当作模型成绩。
- **面试展示**：本轮使用[新讲述稿](AGENT_VALUE_INTERVIEW_GUIDE.md)，使用完整报告的实际数字。原[面试手册](AGENT_INTERVIEW_PLAYBOOK.md)和[能力矩阵](AGENT_CAPABILITY_MATRIX.md)保留历史版本范围。参考项目的借鉴与取舍见[记忆方案分析](REFERENCE_MEMORY_ANALYSIS.md)。

不要用未带源数据的默认手写演示替代冻结神经告警。不要将支付争议实验的6/6成绩用于反欺诈叙事。实际客户端类型、数据来源、实验条件和首次失败回执都应在展示时可查。
