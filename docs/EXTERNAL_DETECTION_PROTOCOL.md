## 数据与模型冻结

- 先审计字段、缺失、有限数值、Time范围和行身份。Time为相对秒，无时区，不伪造具体业务日期。
- 固定时序：Time <86400训练；86400≤Time<129600开发；Time≥129600最终保留。相同时间不会跨分段。不打乱分段，不做SMOTE后再切分。
- 预测输入统一为V1—V28与Amount；Time仅做切分，不提供给模型。缩放器只在训练集拟合；分类标签不进入预测输入。
- LogisticRegression：C=1、class_weight=balanced、max_iter=1000。
- HistGradientBoosting：150轮、learning_rate=.05、max_leaf_nodes=31、l2_regularization=1、early_stopping=False；样本权重正负平衡（只用训练比例）。
- 残差MLP：64维、2个残差块、dropout=.1、AdamW lr=.001、weight_decay=.0001、10轮、batch4096、训练正权重min(neg/pos,50)、seeds42/43/44。记录各seed，平均概率用于集成。不按测试成绩换网络。
- 只允许依据开发AP挑选部署候选；三个家族均报告最终保留结果，不隐藏差的神经模型。开发与最终分两次命令，最终调用前冻结候选、参数、模型及代码哈希。
