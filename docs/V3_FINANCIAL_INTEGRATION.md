# 独立共享接口集成：账本授权上限

本PR仅给版本2模型客户端增加一个可信宿主账本接口`validated_project_limit(run_id)`。账本必须先验证新批次的明确授权和运行范围，再返回项目上限；客户端仍逐请求调用同一账本原子预留。

未提供接口时，版本1/2原20/28上限保持不变。版本1不接受扩展；模型、价格下界、请求/输入/输出限额、usage检查和零自动重试均未改变。接口不接受模型或工具输入作为授权。独立账本的实现及新批次授权不属于本PR，修改此接口本身不批准任何费用或模型调用。

这样新研究批次无需反复改写共享代码中的现金常量，也不绕过已有账本。旧实验源码/结果不重跑，不修改检测特征、权重或标签。客户端测试全部使用MockTransport和测试账本；真实新费用仍必须另获用户明确授权。
