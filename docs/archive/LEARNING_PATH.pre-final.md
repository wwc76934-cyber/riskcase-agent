项目的目标是帮助支付风险分析师核查预警、找证据和验证规则。数据、检测与 PyTorch 首轮之后，已连接真实模型调查、受限规则候选、开发回放与本地版本审阅。工具读取真实存在的本地合成记录，密钥已配置并可自动读取；业务有效性和独立任务价值评测仍未完成。

后续的分工：普通代码负责算账，检测模型负责打分，Agent 负责根据工具结果继续查证据。三部分分别验证，不能用某一部分测试通过代替完整项目有效。

最新开发进度以 [项目地图](START_HERE.md) 为准。较长的工程规格用于查阅，不作为入门阅读顺序。重写前的教学原稿保存在 archive，只供追溯，旧问答和排期不再适用。
