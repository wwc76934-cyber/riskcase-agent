## 同输入与容量控制

Qwen3-Embedding-0.6B固定revision97b0c614be4d77ee51c0cef4e5f07c00f9eb65b3；官方固定版本元数据及本机safetensors的LFS SHA256匹配，许可Apache2。禁止下载更大模型或银行数据发往外部服务。编码只接收公开vocab.csv的1916个API名称，不接收交易、金额、标签或用户资料。

词典描述由固定namespace、原始endpoint及可核对的动词前缀构成。不把ANTIFRAUD接口称作欺诈用户，不为设备、账户或授权状态添加结论；无法解释的缩写原样保留。模板不是对真实请求内容的事实补全。

同时保存1024维编码；预登记只取前32维L2归一化。PAD和缺失/OOV行固定零。相比普通可训练表，冻结分支的可训练参数较少，三个冻结主控制的容量相同；所有下游初值、序列输入、训练日程和公用1916事件本体一致。编码器0.6B参数及离线编码成本单列，不能拿下游同维当全系统等参或把缓存当零成本。

## 选择与后续准入

A3只看开发数据。最终测试预测仍不生成。相对普通GRU、随机冻结、同描述SVD以及强A2数值/TF-IDF组合一并报告；不将胜过弱GRU作为业务必要性证明。

单seed描述置乱/顺序/间隔是机制筛查，不是多seed确认。只有主语义分支对强基线与冻结控制呈可信、跨seed且有配对区间支持的增量，并通过收敛和残留序列关联敏感性，才另登记A4。否则停止融合、自监督和LoRA深化，不再盲目换更大模型。最终测试只在开发选择与所有条件冻结后统一评分一次；一旦打开，不再据其结果调参。
