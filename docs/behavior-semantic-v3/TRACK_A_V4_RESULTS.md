# Track A｜V3 收尾与 V4 语义适配结果

**决定为停止当前 Qwen 语义分支的复杂融合与 LoRA。** V4 的中心化提高了 Qwen32 的开发点估计，但同宽随机表示和普通可训练事件表示仍有更高的 AP。加入相同的发布数值/RFM 后，Qwen128 仍显著落后于匹配随机表示和普通事件编码。低秩下一操作预训练也没有为欺诈排序提供可信增量。

## V3 结论和评分状态

复核了 A2 的 21 个、A3 的 14 个冻结实例和全部 145 项文件 SHA256。模型清单与独立开发重放逐项匹配，最大分数误差 `5.55e-17`，A4 决定仍为 `C_stop_fusion`。V3 的开发结论限于该匿名静态切分。最终测试等待明确批准，当前未读取测试成员或评分。

评分入口的模型加载与推理没有训练调用或选模路径。最终指标只由封存测试记录产生。代码另外重放已冻结开发分数，按已冻结规则计算 F1 阈值，并从训练事件统计切片频次。这两步不改变模型和测试样本。新的批准入口要求用户授权记录与原提案哈希绑定，并在评分前记录单次尝试标记。失败日志独立保留，入口不自动重试。四个预先指定的对照报告 AP 配对序列簇区间及 Top 1% 新增、挤出与净捕获。见 [评分许可检查](TRACK_A_FINAL_SCORING_REVIEW.md)。

## 领域预训练与稳健性

方向性相邻事件的正对数提升量和低秩分解仅用训练池。训练池内部诊断含 343,781 个留出转移，低秩 log-lift 排序的下一事件 Top‑1 为 **0.73%**，训练全局热门后继为 **5.76%**。log-lift 估计关联强度，未校准为下一事件概率。内部留出也无法排除同一用户或相同会话模式关联。把该表用作初始化后，AP 为 .4717，普通初始化为 .4983，三个同种子均较低；前 1% 多捕获一个正例，整体证据不足以推进更昂贵的 Transformer 自监督。

开发集近似训练序列已有 2,293 条，全部为负标签。仅在敏感性分析中排除这些记录，保留相同模型和分数。含数值的普通、领域、Qwen128、随机128 的 AP 分别为 .5016、.4786、.2204、.4163，主要对照方向不变。仅行为的中心化 Qwen32 和随机32 分别为 .0464、.1062。发布方公开仓库、发行记录、论文和可见 Issue 没有提供可验证的匿名用户键、绝对交易时间、官方分组划分、标签确认时间或更详细的事件意图表。无依据从交易相似度推断用户身份。历史 RFM 与终点日志的时点不可核实。若取得所需元数据，可以用独立的用户/时间外推协议检验现有结论。现有作者询问草稿留待用户决定是否发送。[FraudNLP 论文](https://link.springer.com/article/10.1007/s10994-023-06354-5) · [发布方仓库](https://github.com/pboulieris/FraudNLP) · [询问草稿](AUTHOR_CLARIFICATION_DRAFT.md)

## 成本、指纹和复现

- 冻结 Qwen 适配器可训练参数为 6,209（仅行为）或 6,369（加数值）；普通与领域表分别为 67,585 或 67,745。同维随机与对应冻结条件相同。神经单次拟合约 2.78–11.02 秒，四个词法拟合为 7.36–11.55 秒。相邻事件分解与诊断耗时 0.47 秒。
