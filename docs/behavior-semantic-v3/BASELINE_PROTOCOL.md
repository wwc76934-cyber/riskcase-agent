## 固定比较矩阵

| 组 | 模型 | 目的 |
|---|---|---|
| T | 合法数值/RFM＋标准化LR；HistGradientBoosting或RF | 数值强基线；已发布但as-of未知的RFM另列诊断，不混入部署主结论 |
| B | 操作ID unigram/bigram/trigram TF-IDF＋LR、线性SVM；原文RBF SVM配置单列 | 忠实强NLP，不使用普通分词器把API斜线切碎 |
| TB | 相同数值＋TF-IDF＋LR | 保留原文强组合，不让LLM只比较弱随机网络 |
| E | 普通事件Embedding32＋CNN、GRU | 从头训练的行为表示 |
| X | 两层轻量Transformer，宽64、4头、FFN128 | 无预训练语言模型的序列控制 |

TF-IDF只拟合训练集（词ID、IDF、筛选均不可看开发/测试），候选C={0.1,1,10}；强树固定小网格depth/leaf，不逐轮追测试。神经网络统一最多30轮、AdamW1e-3、batch128，开发AP选择检查点、patience5；三个seed，训练预算及实际停止轮都报告。最大长度先按训练池分布冻结256，并固定512敏感性一个seed，不看测试选截断。保留截断比例、截断位置和末端目标事件；截断不能引入目标之后的事件。

对比模块必须使用同一拆分、相同可用字段及同一扰动规则。不同参数量、不同预训练成本和树/神经预算分别列出，不把“同轮数”称同FLOPs。

## LLM阶段的进入条件

先完成并核验T/B/TB/E/X，确定序列增量相对强数值与强TF-IDF的区间。之后才允许在本地核验模型版本/许可，冻结事件词典及同输入编码方案；当前未下载或编码新的Qwen模型。

词典只把已知API映射为忠实短语，保留原事件ID、版本和词典SHA。未知操作用原ID＋unknown，不猜业务；禁止出现标签、欺诈结论、设备异常、授权状态、用户ID或事后信息。事件语义池化与序列Encoder分别比较；长序列截断/分块规则一致。

至少比较普通事件表、Qwen冻结事件表、同一描述的TF-IDF/SVD或轻量文本编码、同维随机冻结、描述对类别置乱；另有数值-only、保留事件多重集但顺序打乱、只保留事件计数和无行为序列对照。顺序打乱不伪造时间间隔含义，间隔分支另做屏蔽。保留原ID控制，防止描述扩写本身新增信息。

只有冻结语义分支对TB及等容量E控制有多seed、配对不确定性支持的主指标增量，且成本可接受，才另登记Gated Fusion、自监督或LoRA预算。不会同时把三种新机制叠加再归因。预训练全模型成本与下游可训练参数分别报告。

无绝对日历时不报告每日Top10。容量代理预登记为每1000笔审核10笔（1%），在固定评测批次K=ceil(.01*N)，报告TopK的TP/FP/P/R及0.5%、2%敏感性；它不是银行实际每日审核能力，也不与IBM TP横比。真实运营预算未知时明确标代理。

报告全部seed与相对强基线的新增/挤出/净捕获、AP差；可用用户键时用用户簇bootstrap。只有匿名行时给出受限描述区间并说明相关性未知，101正例不支持可靠子群结论或大模型端到端标签微调。不得把重复训练当更多独立样本。
