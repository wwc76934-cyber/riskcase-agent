# Track A V4｜冻结的开发探索协议

V4 复用 FraudNLP 的合法本地静态训练与开发切分。输入数值和 Qwen 向量均使用已审查来源。V3 的 35 个检查点、原始结果、A4 C 决定和 145 项冻结指纹保留。V4 输出写入新目录。最终测试不参与探索。

## 诊断和可反驳假设

| 问题 | 已知事实 | 本轮检验及边界 |
| --- | --- | --- |
| 公共方向 | Qwen32 公开事件对余弦中位数 .712，随机表近零。 | 去除公开字典的均值方向再归一化。即使分类改善，也不能区分模板、编码器几何和其他公共内容的各自贡献。 |
| API 语义 | 描述来源于公开路径、命名空间和有限操作词。 | 同文本 TF-IDF/SVD、随机冻结表及几何证据对照。缺乏公开 API 行为细节，路径相似性只作为代理。 |
| 32 维压缩 | Qwen 模型卡支持 32 至 1024 维。V3 训练了 32 维。 | 同一离线矩阵取 128 维，配 128 维随机。32 维与 128 维之间的有效输入秩不同，不能用跨维度增益单独归因于语义。 |
| 监督适配 | V3 已有可训练的 32→64 投影，表自身冻结。 | V4 使用新的受限投影和不同轻量主干。当前实验检验适配表示能否超过匹配对照。V3/V4 差值也包含主干差异。 |
| 截断与数值 | V3 的神经模型看末尾 256 槽，词法模型看整段。Qwen 神经臂没有 RFM。 | 固定同一词法模型的整段/末尾对照，以及所有门 4 臂匹配数值输入。 |
| 收敛 | 训练仅有 60 个正例，开发 23 个。V3 三个 Qwen 种子的最佳轮为 3、21、4。 | 同预算三种子，保存训练损失、开发 AP、时间和参数。结论限定已登记预算及匿名快照。 |

Gate 2 使用末尾 256 槽的四个不相交回看区间。各区间做归一化事件池化，之后共享一个线性投影和小分类头。能区分终点与不同远近区间，区间内部排列不可辨识。冻结 32 维条件用零补至 128 维，名义参数一致但只有前 32 列接收输入。宽度匹配的随机对照隔离这一因素。普通及领域模型可训练事件表，额外容量独立披露。V4 省略间隔，只检验这一架构下的表示问题。

Gate 3 使用训练池中的相邻操作作自监督标签。方向性相邻事件对的正对数提升量经过截断 SVD，得到 32 维可迁移初始化。预训练诊断先保留每十条训练行的第一条，用其相邻事件与训练池全局热门后继比较，然后用整个训练池重拟合迁移表。开发和测试不参与预训练。诊断检验下一事件排序，欺诈增量由 Gate 4 的同结构普通初始化对照判断。

Gate 4 同时提供末尾行为与同一发布数值/RFM 输入。Qwen128 和随机128 在看到 Gate 2 结果前已指定。门 4 能判断冻结语义在含发布 RFM 场景中的增量。历史字段的真实时点可得性仍无法核实。TF-IDF 和组合 LR 的整段/末尾对照复用 V3 已选的 LR 参数，无新增网格。

每个神经实例最多 12 轮、开发 AP 耐心 4、三个固定种子，固定前 1% 静态队列。继续语义复杂化需要同面板对普通和匹配随机的三个同种子差值均为正，配对序列簇 95% 区间下界大于零。开发复用和未知用户关联限制区间解释。协议和代码先提交，再运行。
