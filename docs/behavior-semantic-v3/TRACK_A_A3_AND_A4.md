# Track A A3｜冻结语义对照与 A4 决定

**A4 决定为 C，停止当前语义融合。** 在这批匿名网上银行序列上，冻结的 32 维 Qwen 事件表示没有给出可复核的独立增量。相同的三个种子中，Qwen 都落后于普通事件 Embedding + GRU。相对同维随机向量和同文本 TF-IDF/SVD 的方向随种子变化。结果限定在此公开 API 描述、表示维度、GRU 主干及训练预算。最终测试保持封存。

14 个预定实例全部完成并独立重放，最大分数误差为 0。主结果为三种子的逐样本分数均值，单种子消融另列。队列为 21,219 条开发记录的前 213 条，其中共有 23 个发布正例。

对 1,916 个公开名称的无标签几何诊断中，Qwen32 随机事件对的余弦中位数为 .712，随机表为 −.001，词法表为 .192。Qwen32 的最近邻与原词同公开命名空间的比例为 44.9%，词法表为 92.2%。Qwen128 和 Qwen1024 仅做表示检查，余弦中位数为 .695 和 .687。共享模板、路径缩写及向量集中都是解释假设。命名空间只代理词法相似性，几何检查无法把分类失败归因于某个单一机制。模型卡支持 32 至 1024 维，本轮只训练了预先登记的 32 维条件。[Qwen 模型卡](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B)
