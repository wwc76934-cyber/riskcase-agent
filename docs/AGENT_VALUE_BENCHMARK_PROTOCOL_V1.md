# 多来源欺诈调查评测协议v1

2026-11-01。实施用户新方案，先比较事实覆盖、语义抽取、调查建议及开销。案例是真实源结构上的扩展模拟，不是机构调查资料。C层是作者定义的事实标准与研究处置口径，独立于运行时，未经外部专家审阅。

## 数据冻结

30开发、40冻结评测、20挑战，共15个家族。主体与目标交易按数据组隔离，配对案例只在组内共享A层。A层由同一冻结IBM告警和源SQL导出，B层标记独立模拟。每条B记录保留事件时间、available_at、覆盖、版本及前序关系。C层保存逐条来源事实、关键谓词、可接受建议、必要缺口与解释张力，不进入工具或模型上下文。

模型/提示/基线可以使用开发组改进；冻结组和挑战组的任务输出首次运行后不能用于改进同一版本。机械的数据合同/来源审核不等于外部独立标注。所有格式修正和首次失败单独保存。

## 比较条件

- B0：全量当前授权材料，通用文本抽取与保守规则；不读情景家族、真值或逐案答案。
- B1：同一模型，一次性接收全部当前可得授权材料并回答，允许同等的格式/引用修正。A原始交易和B原件均提供，不以固定三项摘要代替全量资料。
- B2：同模型、相同全部读取能力与限额，根据观测选择来源和修订假设。允许直接选择批量读取，不强迫唯一轨迹。
- B3：B2加受控方法记忆。进一步比较无记忆、原始历史、有效方法、过时/错误方法；语义错误与宿主拒绝分开记录。

记忆条件由宿主在首轮提供已通过范围/时效检查的M上下文，确保实际获得处理；其开销计入工具预算。宿主提供方法和模型主动召回分别记录，不能把自动供给称为模型自主检索。各种记忆条件使用同样的提示与M接口，不向模型标注“这是错误记忆”。

缺失或未来资料对所有条件相同。若做时间推进，各组必须在相同可得时点接收同批资料，并记录刷新成本。访问成本为预先定义的模拟调查单位，不是实际接口账单或分析师时间。

## 质量与失败

综合Q权重在`config/fraud-world-scoring-v1.json`：来源事实支持25%、关键事实覆盖25%、张力处理15%、必要缺口15%、合适建议15%、时间线覆盖5%。同时报告所有原分项、引用校验、错误/无效动作、费用与延迟；不只挑综合分。

来源事实正确性按C层的谓词、值、原件与引用行检查。对认证成功与客户否认的并存，不要求判定严格逻辑冲突。过时规程可以作为历史事实陈述，但不能替代当前适用规程。未读取的原件、未来资料或目录条目不能作为内容证据。

模型选择时间线的事件ID和E引用，可信宿主从已读原件回填事件时间、去重并排序；原始选择、模型填写的时间及宿主改动均保留。时间线指标衡量事件选择覆盖，不将确定性排序和时间抄录算成模型能力。开发实测暴露的E证据/O主张混用与重复启动已用于改进字段说明、标准assistant/tool结果衔接、已完成操作目录和上一版草稿反馈；正式评测前冻结，不据正式结果改动。

严格通过要求引用合同通过、没有错误事实、所有必要事实与缺口齐备、解释张力和建议符合研究参考口径。失败/格式错误/引用拒绝/预算耗尽都留在分母。原始草稿中的资金动作或安全结案建议与宿主实际执行分开报告，宿主始终没有执行资金或账户操作的能力。

自由摘要的完整语义和临床式专家判断不由这些有限谓词自动证明；报告保留人工审阅。研究口径的“错误升级”不是现实机构的损失测量。Q不能换算成欺诈捕获率或人工节省。

## 路径、记忆与成本

配对分析比较同一A层、不同B层情况下的来源访问、计划修订与建议变化；读取ID不同本身不算合理路径变化，需按来源类型和可用信息归一化。脚本探针只验证合同，不算模型规划。

动态路径须记录初始假设和至少一次读取原件后的修订；宿主仅约束可审计状态，不指定业务假设、来源顺序或结论。资料目录支持一次列出全部可得元数据，避免逐类列目录耗尽预算；原件内容仍由模型选择读取。记忆错误归因同时检查已读来源：未取得关键原件时先归因取证覆盖，不能简单把后续补证建议归因“错误停止”。

读取后的修订可以由模型主动调用规划工具，也可以由它提交的终稿假设形成最终审计记录；二者分别标注和计数，不为重复记账额外强制一次模型调用。不将最终捕获称为调查中主动改道。原文与来源层级都由可信原件元数据核对，模型填错A/B标签时记录修正，不将模拟B原件展示成IBM源记录。规程版本是原件元数据事实，引用版本标题也有效；其正确不代表自由文本规程解释已验证。

假设可引用已存在的E来源或O主张，解释张力引用O，行动引用E；不要求无意义地把同一条假设在两种ID之间改写。终稿步骤关闭工具并采用供应商[JSON模式](https://docs.siliconflow.cn/docs/userguide/guides/json-mode)，调查步骤保留标准assistant/tool结果衔接。两条路径共用精简输出合同：最多两个假设，限制重复解释，保留4096输出token和所有原有限额。30份既有强B0开发报告无需修改即可通过此合同；没有删减代码基线事实。

原始历史条件优先采用真实已完成B2开发报告，将回答置于历史正文前；旧标识一致映射为不同的历史代号，超长内容显式标明截断。该材料无C评分真值，不将同一旧答案当作当前案件证据。

## 正式评测前固定的产品选择规则

所有首次冻结/挑战结果均保留，不按结果修改提示、评分或案例。报告每组各分项、Q、严格通过、费用、延迟和安全错误，并按情景家族聚类重采样差值区间，标注仅为内部作者情景的有限不确定性描述。

默认优先较简单路径：若代码在两组的Q均距最好路径不超过0.02、严格通过率相差不超过5个百分点且无新增结构化安全错误，采用代码。否则一次性LLM是默认候选。只有动态路径相对一次性LLM在两组均至少提高0.05 Q、聚类差值区间下界为正，且未增加事实和安全错误，才将其设为默认；记忆在动态路径上也需达到同样的增量门槛。未达到门槛的组件保留为受限研究能力，不编造收益；不能把无显著差异说成已证明等效。

24次开发授权已耗完；修复后的旧响应离线检查不算新模型运行。用户追加同轮预算至10元、项目总上限仍25元，原8元回执与追加回执分别保留；模型、90案、264次案件/1584请求与资料范围不变。两次传输未知费用各按整案0.50元保守占用，并分别披露，不写成已知账单。

来源报告按其提交时冻结的输出协议重验。开发早期至多四个假设的已核验报告保留有限旧协议兼容，不因后来精简文字而丢失已核验来源；引用、主体、时点及证据重算仍执行同样安全检查。保守未知占用之外，已发生的已知usage费用也保留，不能将风险占用误写成供应商实际支出。

记忆候选须绑定实际源报告与独立事实评分/明确审阅，保留错误归因和发布批准。若开发任务没有出现待纠正错误，如实记录，不能伪造模型失败来获得正向迁移。过时拒绝由宿主规则完成时，不计作模型自行识别过时；错误方法影响新案结论时计污染。

模型费用按响应usage与冻结单价估算，保留未知费用预约，不等同提供商账单。新调用先冻结目录、代码、案例、模型与限额，得到具体授权后执行。当前旧批次授权均已耗尽；本协议本身不授权付费运行。

## 开发期接口修订（正式评测前）

用户已明确批准整轮最多264次案件/1584次请求、估算8元，项目总估算上限25元；授权原件不因技术修复改写。首轮9次开发请求因模型报告129个推理token超过128的请求建议值而被旧客户端拦截，费用已据usage记账；当时的对外回答正文在拦截前未保存，无法补造。后续客户端在校验前保存去除思维链的对外消息、usage与模型标识。

新接口按总输出token和费用约束，推理token包含在completion_tokens中，不重复计费。平台的[推理参数说明](https://docs.siliconflow.cn/docs/userguide/capabilities/reasoning)也提示部分模型可能超出建议思考长度。一次开发请求在45秒超时；依据[文本生成说明](https://docs.siliconflow.cn/docs/userguide/capabilities/text-generation)延长技术等待限额至每请求90秒、每案480秒，保留无自动重试。该修订另存并绑定原授权，不能扩大模型、材料、输出、次数或费用范围；任务租约与持久截止同步延长。

未知费用先停止整批；仅可对已终止的具体传输失败作本地操作员风险复核，原预约和未知状态保留，再额外占用至整案0.50元预算，不视为已知账单。该占用同时计入所有新旧客户端的项目与批次预算；新出现的未知费用再次停止，模型替换或仍在途请求不能走此路径。操作员复核不是供应商费用认证，正式报告须分别公开已知usage估算、未知预约与额外风险占用。
