# Gate B：主动加强基线的事后复核

登记时点：主实验Mean及其等参数控制均已完成，已观察到集成TP215、137；强平面138，增强统计神经网络151。其余注册架构仍在运行。

为排除“只选了较弱的统计特征模型”这一解释，追加**一次**固定的历史统计+强树挑战，不修改原36个主实例或2个K敏感性实例的协议、预算、结果或选择规则。该挑战标记为posthoc robustness control，不包装成事先注册的主比较，也不触发超参数搜索。

- 输入：同一批2016–2017训练、2018已观察开发的原12个数值字段、MCC和已冻结14项用户卡last6统计；不包含channel、身份、标签或事后资料。
- 方法：原强树相同的100迭代、15叶、学习率0.1、min_samples_leaf50、L2=1、class_weight=balanced、early_stopping=false、seed42；CPU2线程。
- 同一统计数组、行序、来源哈希和训练期词表必须验证；无论是否超过神经历史模型都保留结果。报告成本、AP、每日Top10与渠道分配。
- 这不是与神经网络等损失或等参数的因果比较；用途是检验更强、更便宜的业务备选方案。若更好，应如实推荐较简单路线，不因已实现GRU/Transformer而拒绝负面结论。

另外登记统一描述性不确定性复核：除原配对日自助区间外，对各主要历史对照报告固定7天循环区块、5000次、seed1217的配对区块区间，以观察时间相关影响。不得挑选对候选有利的区间，不据此追加模型搜索。

## 统计信息覆盖的最终加强（仍为事后挑战）

首个14项统计+强树结果为TP127、AP0.01409，完整保留。14项主要覆盖金额、age和当前MCC匹配，尚未覆盖Mean读取的全部历史数值向量与类别构成，不能据此声称排除了“普通统计信息”解释。

因此一次性登记最终的广覆盖统计挑战：对同一last6，计算原训练期预处理后的24个数值/缺失指标的均值、标准差、最近值、当前减均值，以及所有训练MCC的频率，再加原14项统计。当前数据共220维，提取器不接收标签、身份或channel。

固定比较一次原100×15强树（seed42）及一个32维统计瓶颈+与当前表示融合的门控残差网络（seed42/43/44，12轮、同BCE20/AdamW/余弦预算）。统计网络参数量比Mean略多，作为加强的业务控制，不伪称完全等参数。原Mean-self精确参数控制继续保留。

追加这4个实例后停止扩展Gate B控制，不根据它们的结果新增特征、搜索树参数或选择更好seed。它们属于看到Mean与14统计对照结果之后的保守挑战，不能包装成预注册主实验；全部正负结果及成本须保留。
