# 回执与数据访问范围说明

此说明澄清术语，不改变已经冻结的模型、mask、预算或选择规则。

## D的“只用训练池”

D的优化worker只接收train分区X、841,892行训练前缀统计矩阵和-1/0/1标签向量；采样索引严格小于训练行数。未标注行的监督损失为零，额外一致性只使用训练池软目标。开发行不参与学生、教师、scaler或词表更新。

复用的B缓存物理文件同时保存训练和开发统计，启动时进行整文件SHA校验并建立只读内存映射；这是字节完整性检查和共享缓存映射，不是把开发行送入训练前向。不能把“训练分区加载”误述成“整个进程此前从未接触过任何开发字节”。

B的开发汇总指标已经用于历史模型研究和D准入，这是已观察开发协议。延后的是**本轮D新权重的开发评分**：27个主模型、4个固定续训、1个树全部完成并记录权重指纹后，才调用完整开发加载/评分。没有将这个流程包装成新独立盲评。

## 概率、标签与假设

教师sigmoid是相应加权目标下的模型分数，未做概率校准；其均值不是真实隐藏欺诈率。KL是一致性约束，不把软目标认定为调查结案或全正常真值。

7日标签延迟是假设。source-local合成事件日历没有已证实时区；原数据actual available_at仍为空。隐藏正例数量只能作为控制器在拟合结束后的合成真值核验，不能据此宣称真实未标注业务群体的比例已知。

## 文本与模型指纹

新阶段使用的已跟踪门控回执history-results.json/history-review.json统一为UTF-8 LF，并在本目录.gitattributes固定。它们在本机与Git提交blob中逐字相等。原始忽略目录中的训练、数据、权重、日志仍按原始字节计算SHA，没有因换行规范化而重写。历史B源文件的工作区/提交编码映射继续见SOURCE_IDENTITY.json。

GitHub发布通过已连接账号的Git Data接口；已核对整个内容树，并保留本地原始提交备份，再只对齐分支引用。未假称缺少原生凭据的git push成功。默认模型与调查Agent语义没有因此改变。
