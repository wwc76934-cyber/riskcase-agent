# Gate B：充分监督历史建模协议

Gate A已实际完成28个训练实例及独立核验，见`gate-a-results.json`。本协议在任何Gate B真实数据模型训练前冻结，不混入语义或一致性机制。

- 使用普通可训练的MCC32附加表示、原raw/no-channel残差核心；所有模型从42/43/44三个seed冷启动。选择这一强平面核心依据Gate A已观察开发结果，属于开发决策，不是独立外部选择。
- 每个模型12轮、batch4096、AdamW起始0.001、固定余弦降至0.00005，正类权重20；固定末轮，只在完成训练后评分2018，不选最好轮次或seed。保存每轮loss、正负损失尺度、logit梯度绝对量、裁剪前梯度、耗时和优化器检查点。
- 主K=6事先固定；Mean的K=12/24只在seed42作注册敏感性分析，不据此选择主K或选择有利架构。
- 主要条件：平面模型、增强确定性统计模型、Mean、时间尺度24小时的衰减Mean、GRU、单层4头历史Transformer、单跳带时间项Attention。五种历史架构各有一个完全相同参数量的当前交易表示控制，共36个主训练实例，另2个K敏感性实例。
- 当前表示控制只读取当前交易的既有特征，不读取实际邻居、邻居数、卡片ID或实际age；重复当前表示并保留对应架构和固定位置，以使网络参数能够参与运算。它不是将所有输入简单置零的弱控制。已有点特征本身含原先允许的用户级历史聚合，报告中明示这一边界。
- 新邻域严格以(user_id,card_id)分组。卡片编号不能脱离用户当全局ID；原始事实库独立关联并核对时间、split及用户。训练图只含2016–2017节点；推理图可读取目标之前的2018特征但无任何标签。2015只通过既有合法warmup点统计存在，不新增图节点。
- 同刻交易先查询后整批插入，彼此不可观察。所有边逐条核验时间、用户、卡片和age，并用独立源SQL重建随机256个目标的last-K。GRU只处理有效的按时间顺序邻居；Transformer只能看到这些过去记录，不构造未来全图。
- 确定性统计固定为14项：K内计数、金额均值/标准差/最小/最大/中位/绝对均值、当前金额相对绝对均值、相对最近金额变化、相同MCC比例/最近同MCC、平均/最近/最远age。其缩放只拟合训练期，输入不含用户ID、标签或后续结案信息。
- 保留原冻结残差、强树、旧平面B1及旧两轮Mean/Attention作为带配置说明的参照。直接历史归因优先比较同预算强平面、等参数当前控制和统计基线，而不是只超过旧两轮弱模型。
- 主指标仍是365天每日Top-10捕获；同步报告Precision/Recall/AP、渠道名额/TP/FP、新增/挤出/净捕获、多seed与配对日描述区间。区间不是独立测试显著性证明，不把多次开发结果当新留出。
- 相同轮数和优化步骤不等于相同FLOPs；逐模型报告成本。内存是包含数据/图/历史高水位的整进程指标，不据此宣称独占模型显存或生产吞吐。

无论结果如何，不自动替换默认检测器，不修改调查合同，也不将历史模型分数解释成欺诈认定。若仍有明显未收敛迹象，先按保存的曲线明确指出，不能临时追加无限搜索或改选更好看的轮次。
