## Gate A1：先审计，后新训练

重新加载原权重对训练期评分，核对开发期分数与原回执；分年份统计 channel/MCC 组合的样本量、标签率、分位数、尾部和日排名。主要模型为原冻结残差、强树、上一轮 B0/B1/B2/B3/shuffled、历史 mean/attention，各 seed 与均值均保留。

渠道分布比较报告效应量及列联检验；标签率差异报告正负样本计数，不把小 p 值当语义因果证据。对同一交易计算确定性日内排名，保留原 tie 规则；输出新增/挤出正例及渠道流向。样例只在报告中展示交易哈希别名，完整本地回执供复核。

## Gate A2：2×3 匹配实验

channel=false/true × 原类别编码/普通附加32维/冻结语义32维。原始12个数值字段、原 NeuralPreprocessor、原残差核心、优化器、batch4096、正类权重20、5轮、seeds42/43/44全部匹配；固定末轮，不选最佳 seed/epoch。共同核心在附加模块初始化前构建，保证同 seed 的共同参数初始化一致。

无 channel 条件必须同时删除数值/类别通道和文本中的渠道信息；联合类别键只含 MCC。不能仅屏蔽一条输入通路。历史原模型作为参照；任何复用权重必须验证真实训练配置、代码与行序一致。

本轮附加表示逐行L2归一化，固定/随机向量及可训练Embedding一致；unknown附加行统一为零，原类别分支仍保留。原E1可训练附加表默认标准差1，而冻结语义表为单位范数，这是须报告的输入尺度混杂，不能直接当作预训练知识无效的证据。共享残差核心先初始化，附加模块在独立随机状态中初始化，避免改变共同核心和dropout初始随机状态。

## Gate A3：有限语义诊断

对上一轮272条唯一文本检查完整余弦矩阵、最近邻、行业聚合、渠道可预测性；交叉验证按 MCC 分组，不能让同一 MCC 的其他渠道副本泄露到验证组。

相同既有 Qwen 0.6B 权重只执行冻结编码，保留完整输出，比较前32/128/256维；不增大编码器。文本只来自已允许的 Visa 标题、明示的行业抽象规则和渠道类别。未知/冲突 MCC 仍 unknown。

下游有限筛查沿用A2的原始数值输入、channel=true、5轮和seed42：32维原文本（复用A2）、128/256维原文本及各自同维可训练/随机对照、32维行业描述、32维描述打乱、32维类别对应打乱、32维等维随机冻结向量；普通可训练32维来自A2。共10个新增筛查条件。打乱规则在运行前固定，未知行不变，渠道字段在描述打乱中保留。单seed筛查只作机制探索，不能作为稳定增益或晋升证据。

只有筛查中同时超过同维普通附加Embedding和同维随机向量、且AP也超过二者的最佳一个语义候选可补seed43/44（排序依次为超过较强对照的净TP、AP、条件名）。行业文本还须超过原文本。补齐对应普通/随机对照的seed43/44，最多追加6个运行，不单独给候选增加训练预算。需进一步报告多seed、配对日区间与选择偏差；若不满足条件，停止IBM上的更大语义尝试。不能把开发筛选后的区间当独立显著性。

## 后续顺序

Gate A 报告必须在任何 Gate B 新模型训练前完成。Gate B 单独冻结至少10轮、多seed协议；原冻结模型、强树、平面、等参数无邻居和增强确定性历史特征必须同时保留。主K固定，或先声明小网格和选择规则；不事后挑K。严格时间/用户/卡身份审计、重载、分渠道名额、曲线、开销和配对不确定性为必要交付。

Gate C先独立核查 MS-FFSD / IEEE-CIS / 模拟数据的来源、许可、时点文本与划分；不把新数据可下载等同于合法时序语义可用。Gate D最后，须先有可靠时点/标签可得性合同。未经准入不训练，不强求LLM或复杂历史架构胜出。
