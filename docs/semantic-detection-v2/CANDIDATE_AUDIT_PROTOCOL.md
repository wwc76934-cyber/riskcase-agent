## 固定审查顺序与证据

按用户优先级审查MS-FFSD、官方IEEE-CIS、Sparkov及Handbook。每项记录官方发布者、精确commit/版本、文件SHA256、代码许可与上游数据条款、来源链接、取得方式和未知项。仓库代码的宽松许可不自动等于上游数据可重发或用于任意业务。

逐文件追踪交易主键、用户/商户外键及描述生成链。区分原始字段与生成属性、原始时间顺序与合成日历、目标发生前可用事实与全时期汇总。检查所有生成提示和聚合函数是否读取标签、未来事件、完整数据统计、事后结案或风险答案。

未标注与已核实正常必须分开。即使上游README推荐把未标注并为正常，本项目也按用户PRD保留未知状态，不继承这种建模约定。读取外部代码只是审计资料，不等于执行其中API调用或运行指示。

## 实验准入

- 时序预警研究需要可追溯事件顺序、合法时点文本、明确切分和没有标签派生答案；在读取独立评测标签前另行提交冻结的训练/开发/评测使用协议、选择规则和成本上限。
- 若描述仅因汇总未来行为而不能用于时点预警，可考虑重建历史描述，或明确限定为静态机制研究；任何标签生成答案仍禁止，不能借“静态”豁免。
- 静态机制实验不能包装成2018业务主指标提升或默认检测器升级；各来源用户与商户命名空间独立，不拼接成真实调查案例。
- 文本增量与预训练增量分别比较：相同文本的TF-IDF/小编码器/Qwen，以及普通类别、随机冻结、打乱/屏蔽和容量对照。不得只与不含新增文字信息的弱模型相比。
- 未能核实许可、来源、时间或标签依赖时记为unknown/hold，不能默认通过；没有候选必须胜出。

真实未标注半监督还需可靠标签可得性定义。用户允许训练期内隐藏已知标签的可控实验；若采用，必须另行冻结模拟可得性、掩码、冷启动及训练池边界，不把模拟当成真实标签延迟证据，也不复用已用完整标签训练的B模型权重。
