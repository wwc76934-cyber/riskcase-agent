# RiskCase Detection V2.1｜本轮研究结论

本轮已完成Gate A、Gate B、C1来源准入审查，以及既有合成数据上的可控Gate D与固定9实例类别先验补充。**不升级默认检测器，仍为neural_v2_ensemble。** C2新业务文本没有合格数据准入，不以更大的Embedding模型继续IBM搜索。本报告是检测研究结论，不是调查Agent集成或真实机构效果验收。

## 两个相互独立的结论

**交易历史信号有明确的开发价值，Mean Pooling的独立架构优势尚未确认。** 原冻结检测器捕获122条，12轮三seed Mean集成捕获215条；同参数、不提供真实邻居的self控制为137条。Mean相对self净增78，七日区块描述区间[54,104]，说明收益不只是多加参数。但广覆盖确定性220维统计网络已达196条，Mean只多19条、区间[-5,45]，不能认定神经历史表示稳定超过强统计。两者都保留研究身份，优先考虑成本更低的强统计挑战与新的独立验证，而非直接换默认模型。

**当前没有预训练语言表示的稳定独立增量证据；在充分且合法时点业务文本上的价值仍未验证。** 完整监督公平矩阵中，无channel普通Embedding131、语义126；有channel普通71、语义55。低标签固定补充中，Qwen98、普通97、同维随机93、同文本TF-IDF99；Qwen相对普通的三个同seed差为-2、-9、+8，集成+1的七日区块区间[-9,11]。相对TF-IDF为-1、区间[-8,6]。AP点估计较高不能替换每日Top10主指标。本轮停止IBM语义搜索，不把负结果解释成所有LLM或业务文本永远无效。

## 问题一：为什么Online占用过多审核名额

旧B2向Online分配3350/3650个名额，原模型仅745。渠道交易占比大体稳定，标签条件分布却明显改变：2016 Online50750笔、773正例，2017 Online50095笔、0正例，2018 Online50576笔、28正例；Chip分别65、63、564正例。原始选中交易的1263980个标签已逐条与CSV核对，另128笔字段抽查通过。此处是固定合成群体的跨年份分布证据，不臆断真实银行原因。

保留旧模型渠道内排序、仅换B2每日渠道名额，捕获从122降至42；保留旧名额、换B2排序则为120；实际B2为45。B2的Online内部AP约.569，甚至远高于旧模型约.028，却将全局名额分配错位。这个双路径交换把“渠道内排序”与“全局队列分配”分开，不能将交互项当唯一因果份额。

匹配矩阵进一步表明：不使用channel时原编码/普通/语义为122/131/126，使用channel时52/71/55。同组输入、初始化、预处理与预算一致。不能拿不同输入的旧残差网络差距，全算成LLM向量的影响。向量行业近邻合理、channel容易解码，也不等于任务排序有效或证明唯一失效原因。详见[ROOT_CAUSE](ROOT_CAUSE.md)、[CHANNEL_AUDIT](CHANNEL_AUDIT.md)、[SOURCE_DIAGNOSTICS](SOURCE_DIAGNOSTICS.md)。

## 问题二：为什么简单历史平均有用，注意力未胜出

38个预注册12轮实例包含平面、14维统计、五种历史模型及各自等参数self控制，另5个明确事后登记的强统计挑战。43实例全部完整重算422088笔，误差0；220维新增历史统计全部独立重建，误差0。新邻居严格早于目标，同刻隔离，按用户-卡身份构建；原始点特征中保留的用户级历史量另有披露。

平面138、14维统计151、Mean215、时间衰减196、GRU202、轻量Transformer207、Attention199、220维统计NN196、统计树158。K12/24单seed为222/214，仅作为冻结敏感性，不回头把K6主方案改成最好看的设置。Attention在充分预算下并非旧两轮结果那样失效；其有效邻居数约3.6，没有全体塌缩成单邻居的证据。Mean优势的一部分可由普通历史统计解释；注意力为何未超过Mean仍有优化、样本量和归纳偏置等候选解释，不将这些假说包装成已证因果。详见[HISTORY_RESULTS](HISTORY_RESULTS.md)及[HISTORY_DECISION](HISTORY_DECISION.md)。

## 问题三：语言预训练在什么条件下可能有价值

当前MCC描述是类别ID的确定函数，没有新增逐交易业务事实，训练/开发也没有形成未见MCC的零样本检验。充分监督时普通类别表已可学习；91可见正例时，固定Qwen仍未稳定超过同文本TF-IDF和普通类别表。这个结果只约束当前类别先验设计。

MS-FFSD默认代码存在全样本标签统计→商户类别改写→文本的依赖，且时间包装器使用label-aware合成时间。发布ZIP未打开，不推断实际受影响比例或所有发布行均受污染。IEEE官方账号权限与规则接受未核验；没有用镜像绕过。Sparkov/Handbook适合模拟机制对照，但本次未确认充分的合法时点业务文本。C1因此不准入C2，不拼接不同数据源成真实用户调查案。

后续只有先核实许可、主体关联、原始时间、描述as-of及标签发现机制，排除标签/未来行为生成文本，再冻结数据使用与选择规则后，才值得比较同文本TF-IDF、轻量Encoder、Qwen及随机/打乱控制。当前不能声称已经证明在丰富业务文本上的语言知识价值。详见[CANDIDATE_AUDIT](CANDIDATE_AUDIT.md)和[LOW_LABEL_PRIOR_RESULTS](LOW_LABEL_PRIOR_RESULTS.md)。

## 可控半监督：损失配置不能混同机制证明

训练池841892笔，仅83057条可见标签、91正例；7日延迟是假设，真实available_at未知。隐藏部分含876个合成正例，未被当作正常。BCE97、标准Focal121、权重匹配Focal105、类均衡Focal99、可见标签树108。标准Focal比BCE多24，区间[7,41]；但其原类别比1:3，而BCE为20:1。匹配类别比后仅+8，区间[-1,17]，不能将24全部归给Focal调制。

四种一致性相对BCE为+1、+2、0、+3，区间全部跨0。额外视图对照与所有seed完整保留。四个固定seed42延训6轮后TP分别90→91、113→106、93→94、94→94；loss继续下降不等于业务排名改善，本轮不再追加搜索。原32实例全部独立重算，误差0。补充9实例先于原D开发评分公开登记，始终使用同BCE20配对；标准Focal121另列业务上下文，未为语义更换弱参考。详见[SEMI_SUPERVISED_RESULTS](SEMI_SUPERVISED_RESULTS.md)和[技术判断](SEMI_SUPERVISED_DECISION.md)。
