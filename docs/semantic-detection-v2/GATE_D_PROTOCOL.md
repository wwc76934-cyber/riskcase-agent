## 损失与梯度的可解释比较

标准Focal的一般形式是`-α_y (1-p_y)^γ log(p_y)`。α=.25的正负类别比为1:3；它与BCE20并非只差γ。因此额外保留α=20/21的对照，使正负类别比仍为20:1，再检验难例调制。两种Focal都报告，不能挑弱版本来展示另一方法获胜。

类均衡原权重为`(1-β)/(1-β^n_y)`，按可见类别频率归一化。三种Focal各乘预先定义的全局尺度，使**参考概率p=.5**下的可见样本期望loss等于BCE20；这不声称实际随机网络输出都为.5，也不同时匹配梯度/曲率。

保存原系数、固定尺度、实际正负数量、参考概率.001/.01/.1/.5/.9处的logit导数，以及每轮真实正负监督损失、logit导数幅度、batch归约总量、整网梯度范数和裁剪比例。不得把logit导数当整网梯度，也不得把短预算未收敛直接叫方法无效。

## EMA与合法噪声边界

教师为学生权重EMA，衰减.99，无训练梯度。前2轮一致性权重0，随后3轮线性升至.1或.5；教师概率裁到[1e-6,1-1e-6]，使用未知项Bernoulli KL，不生成全正常硬伪标签、不搜索阈值。

所有模型都保留原网络Dropout.15。“无额外视图”仍有该模型噪声。额外视图只对模型内部64维上下文激活做.1 Dropout，源金额、类别、日期和邻居身份不改写；不作强业务不变性宣称。bce_view隔离一般正则化；额外视图下有/无一致性也配对比较。

为匹配计算路径，λ=0控制也进行无梯度教师前向；这是路径匹配控制，不是最省算力的监督实现。教师不参与最终排序，只评固定学生。CPU成本完整披露。
