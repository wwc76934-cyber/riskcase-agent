# D补充｜低标签类别先验的有限对照

本协议在本轮D开发评分产生之前登记，补齐PRD的“有无预训练语义”要求。**原D的32实例、代码、预算与结论不改写。** 先完成原D32实例独立核验，再执行本补充；不根据原D分数选择是否执行或修改超参数。

这里只复用Gate A已审核的无channel MCC描述和本机Qwen0.6B缓存，考察相同类别先验在91条可见正例下是否有用。它是既有类别信息的回顾性机制对照，不是C2新业务文本研究；C1的新候选数据准入仍然不通过。没有更大的Embedding模型、模型下载、原始交易文本化或新API调用。

## 固定比较

普通可训练类别Embedding直接使用原D的bce三个seed作为参考。新增三组，每组seed42/43/44、12轮，共9个新实例：

1. A已冻结的nochannel-original Qwen向量，取前32维再L2归一化并冻结。
2. 相同形状、固定seed20261102的L2随机冻结向量。
3. 相同MCC描述的TF-IDF（词1/2gram、sublinear_tf）＋固定seed的32维SVD，L2后冻结；只拟合训练类别文本，未知行固定零。

原始文本、类别键和向量文件SHA绑定配置。禁止加入用户标识、欺诈标签、调查结案或目标之后的行为。MCC无关用户身份；不拼接不同来源案例。

## 公平性与隔离

使用完全相同的83,057可见标签（91正例）及mask SHA，严格训练前缀的同一220维统计、同一训练X预处理、相同batch4096/12轮/AdamW/余弦/clip5。只用BCE20、无一致性或额外视图；保留原D bce的教师前向/EMA计算路径以匹配计算，最终仍只评分学生。

每seed先构造普通模型的冷初始化，复制全部非auxiliary参数到三个冻结向量模型，再只替换并冻结32维auxiliary表。因此下游容量、形状与初值匹配；随机和TF-IDF与Qwen的可训练参数量完全相同。普通可训练表参数略多，作为强基线单列。禁止加载完整监督权重。

9个模型全部拟合完成后才评分新权重；独立重载每实例全部422,088笔，核验原D参考及分数指纹；报告每日Top10、AP、渠道名额、增量/挤出、多seed和配对日/区块描述区间、训练CPU和推理成本。所有结果并列，不选最有利维度、模板或seed，不追加更多IBM语义搜索。

## 解释边界

这些描述是已知MCC类别ID的函数，没有新增逐交易业务事实。本补充只检验稀疏标签时的类别先验；即使出现增量，也不能单凭它宣称在丰富业务文本上的语言世界知识价值已经证明。

现代字典/预训练模型用于历史合成数据，是回顾性研究，不是历史线上可得性验证。2018已观察，2019已观察且本轮不评测；不产生新独立留出。只有相对普通Embedding、随机向量及同文本TF-IDF均有稳定增量，才讨论受限条件下的预训练先验价值；默认仍保持neural_v2_ensemble。
