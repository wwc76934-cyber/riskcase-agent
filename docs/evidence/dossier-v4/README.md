# 可携带的真实模型证据包

这是**自建合成资料、六个已观察案例的修复回归**。不是外部测试集、真实客户或生产收益证据。所有文件从本机已保存实验复制，没有重新调用模型，也没有上传到外部服务。

- `report.html`：离线打开即可选择全部12次运行，核对每项主张与原文；无外部资源依赖。
- `scores.json`、`acceptance.json`：完整分母与事先约定门槛；两组各6/6。
- `comparison.json`：V2/V3/V4首次失败及修复结果并列，不能把三轮当独立样本。
- `raw-10/`：资料缺失案例的两条路径，完整请求/响应、结果、评分和费用审计。动态模型逐步取证；全部资料路径一次获得全部原件。
- `failures/`：V2预算耗尽、V3已知缺口与行动矛盾的失败原文。
- `costs.json`：V4估算费用1.088652元，项目累计13.048320元；是本地估算，不是供应商账单。
- `manifest.json`：各复制文件的原路径和SHA-256。`frozen-manifest.json`记录付费实验的源码/案例指纹。

动态组读取4份原件而简单组读取8份，但模型请求是5倍、费用约2.89倍。小案卷默认全部资料输入，不只展示有利指标。所有结果仍需人工确认语义；浏览器测试中的模拟审批不等于专家审阅。

完整本机冻结源码与全部原始文件在 `runs/stage5-freeze-v4/`、`runs/stage5-live-v4/`；当前产品入口的记录器抽取与付费版本类定义AST一致，新增入口本次没有另做付费模型实验。更完整的边界见 [阶段报告](../../STAGE5_REPORT.md)。
