# 欺诈记忆与本机运行证据

此包只含摘要、浏览器回执及校验清单，不含原始交易、数据库、模型密钥或真实模型调用材料。`simulation-dryrun.json`明确是模拟客户端，不是LLM成绩；它在规程v2与最终模式隔离修复前执行，最终代码以204项集中回归和最新浏览器回执验证。

`capacity-original.json`保留首次负载结果及错误的0/32审计评分。`capacity-audit-correction.json`关联原文件SHA-256，说明评分器混用JSON指纹合同，按正确MCP证据合同重评同一批记录为32/32，未重跑工作负载、未改动耗时或任务原文。

`test-receipts.json`引用本地原始JUnit文件哈希，保留首次失败和修复后结果。多个运行存在重叠，不能把测试数相加。容量实验复用四个源案例，不是32个独立案件或银行生产压测。
