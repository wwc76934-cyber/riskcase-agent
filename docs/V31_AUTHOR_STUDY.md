# V3.1 作者审阅模拟对照

## 研究边界

任务从支付欺诈告警开始，交付当前证据、相互矛盾的事实和下一步调查建议。参考中的认可、否认和未知属于目标支付的来源陈述。所有调查材料均为作者模拟，结论适用于这个模拟环境。人工审阅耗时、银行真实效果及法律责任尚无观测。

新版包含 40 案、10 个家族。30 案继承已经过 AI 作者复审的 v4 语义候选，在新版中细化来源角色、加入认证失败和变动窗口，并修订一个可有两种解释的时点参考。10 案新增付费取证，包括商户分笔入账、账户恢复、短时档案和有条件授权。案例可经历后到更正、实际查询不可得和到期。继承记录标注原材料指纹，原有 v4 与 90 案实验另存。新版是已观察、AI 作者审阅的模拟工程研究。

## 评分和强基线

每案三个阶段均保留原始分母。评分逐项核对交易归属、行号来源、当前陈述、历史反证、关键查询回执、资料缺口、建议与停止条件。资料未返回时可保留不可得回执。回执不提供原件行号。正确标签若只引用被后续纠正的陈述，也无法通过该阶段的来源要求。参考未覆盖的结构有效事实单列，正文语义与人工效率单列为未测。

40 案均经离线可达性审计。评分必需的证据有预算内路径，其中两例要求在查询确实返回不可得后继续查替代渠道。纯 B0 在当前模拟协议下结果如下。

| 指标 | 结果 |
|---|---:|
| 成功交付阶段 | 120/120 |
| 关键证据组取得 | 224/230 |
| 目标声明及来源正确 | 78/120 |
| 严格通过阶段 | 78/120 |
| 三阶段均严格通过 | 13/40 |
| 外部模型请求 | 0 |

B0 具备确定性来源排序、过期、费用、身份角色和撤回处理。B4 复用 B0 的取证并采用同源语义交付合同。B1 优先收齐所有现有资料，预算确实不足时允许一次批量选源，报告可作一次有界协议修复。B2 在同一来源世界更新计划并通过本机 MCP 实际读源。三组模型的合同与线路通过本机脚本验证。正式结果需另行采集。

## 对照计划与验收状态

固定 40 案×3 次重复×4 条路径，随机顺序种子 20261104。B0 的重复复用相同确定性结果。主终点为每案三阶段严格通过，先分别比较 B4 对 B0、B2 对 B1 和 B2 对 B4。按案件配对、按家族成块重采样 2000 次。所有失败计入全样本指标，交付后的质量另报。B3 等稳定 B2 后再研究。

此版仅冻结离线设计。Gate 3 仍由单独的六案开发复验决定。正式运行器、付费授权、正式模型输出及新分支双平台 CI 尚待落实。计划的模型组在最坏情况下会发送 3960 请求。即使用开发请求的统一费用上界估算，单次重复的总预算也需要单独核对，不能从现有开发授权推导正式对照额度。
