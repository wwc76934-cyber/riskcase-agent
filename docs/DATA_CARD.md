# 当前数据是什么，结论能用到哪里

初始核查：2026-10-15；结项补充：2026-10-22。对象是 IBM TabFormer 固定提交下的交易归档，不代表所有同名 Kaggle 镜像，也不代表本项目自行生成的数据。

当前交付状态见[结项报告](FINAL_REPORT.md)。模型使用固定408用户身份群（分期活跃用户不同），2016–2017训练、2018开发、2019最终时间评测。全部年份的分区行数/标签聚合计数早期已经盘点；最终模型排名与指标在权重、代码和名单冻结后首次评测。不能称为此前完全未见任何2019标签信息，也不能称为用户完全隔离测试。

## 身份和来源

- 上游：[IBM/TabFormer](https://github.com/IBM/TabFormer)，对应 ICASSP 2021 论文《Tabular Transformers for Modeling Multivariate Time Series》。官方明确称其为 synthetic credit card transaction dataset。
- 固定版本：`ebb7cd68ee1897599568107740bc452104bbbaf8`。
- 文件：`data/credit_card/transactions.tgz`，归档内 CSV 为 `card_transaction.v1.csv`。
- 完整归档大小 278,576,638 字节，SHA-256 为 `e9f589a0958f40d60f81b1a2e8428db86e00c05755caf44fb055827976c0efa2`；本地已核验，本批剖析前再次核验。
- 论文引用的生成背景：[Synthesizing Credit Card Transactions](https://arxiv.org/abs/1910.03033)，利用虚拟世界、信用卡处理与消费领域知识模拟交易。不是银行脱敏流水；本项目没有审计生成器或复现其生成过程，不能声称核验了每个生成机制。
- 本项目可重跑固定文件的处理，不等于能够从生成器与种子重新生成完全相同的原始数据。

## 记录含义

一行是一条上游交易记录，包含用户、用户内卡编号、年月日时间、金额、交易渠道、商户标识、商户城市/州/邮编、MCC、错误信息、欺诈标签等。以实际 CSV 表头为准，不照抄 README 的字段数量。

User、Card、Merchant Name 用于合成实体的历史查询；Card 按 User 组成联合键。行号是物理引用，不是上游业务交易号，不能以行号不同证明没有业务重复。

Is Fraud? 的 Yes/No 是合成环境的结果标签，不是现实调查员确认欺诈。数据未证明提供标签确认时间、入库时间或每个字段在授权前的可得性。调查 Agent 不读取该标签；离线评测单独使用。

金额原文带 `$` 显示符号，但当前合同未确立币种；负数保留且单独统计，不能未经核实直接称为退款。时间没有明确时区合同，不能任意转成 UTC。金额不能直接解释成实际欺诈损失。

字段使用还需遵守以下区别：商户城市不等于持卡人的实时位置；Merchant Name 的数字外观不表示连续数值，不应按大小计算“商户距离”；Errors? 的空白可能表示没有记录错误，不能直接称为数据损坏。Errors? 是否为交易处理后的结果尚未确证，初始授权前检测模型暂不使用它，防止把事后信息当预测依据。

## 四种“可靠”分别验收

| 维度 | 当前结论 | 不能推出的结论 |
|---|---|---|
| 来源、版本完整性 | 官方固定提交和完整文件哈希可追溯 | IBM 出品不等于逐条记录正确或代表现实 |
| 字段和统计质量 | 做全量字段、类型、缺失、标签、时间与排序剖析 | 类型通过不等于无业务重复或无泄漏 |
| 调查可用性 | 有用户/卡/商户/时间，能查合成历史 | 没有设备/IP/资金去向/真实人审记录，不能编造完整案件原因 |
| 外部有效性 | 尚未证明 | 不能由合成集效果推断国内支付场景效果 |

## 使用边界与许可记录

固定提交的[仓库 LICENSE](https://github.com/IBM/TabFormer/blob/ebb7cd68ee1897599568107740bc452104bbbaf8/LICENSE) 为 Apache-2.0，数据目录 README 提供归档和 IBM Box 链接。当前未找到更明确的数据专用授权说明，保留数据再分发范围的待核实项，不把仓库代码许可自动写成已确证的数据商业使用许可。

原始数据、抽样、事实库与全量含标签统计保留在本地忽略目录；本仓库交付代码、来源说明和汇总证据，不发布原始交易。正式公开演示的样例另用项目自建夹具。

## 对本项目的决定

继续用它开发和检验数据管道、历史特征、工具调用、证据引用、规则离线重放，并报告明确标注为合成环境的模型对照。它是当前开发数据源，尚未通过作为“唯一最终业务验证源”的验收。

真实匿名源的许可、可获得性和字段适配仍是独立门槛。匿名数据若没有实体键，只能用它支持分类实验，不能把它和 IBM 合成用户拼成真实调查案例。若最终无法取得适用来源，就如实交付合成业务环境工程原型，不能保留“已验证真实风控效果”的目标表述。

全量标签汇总只用于数据适用性核查；之后预先冻结时间切分与评测口径，不按保留集效果回头挑客户、改阈值或选择特征。
