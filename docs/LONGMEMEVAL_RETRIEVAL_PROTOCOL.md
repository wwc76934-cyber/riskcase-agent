# LongMemEval-S独立检索协议（执行前冻结）

2026-10-31，内容下载前固定。官方仓库：<https://github.com/xiaowu0162/LongMemEval>，清洗版作者数据集：<https://huggingface.co/datasets/xiaowu0162/longmemeval-cleaned>。

- 固定revision `98d7416c24c778c2fee6e6f3006e7a073259d48f`，文件`longmemeval_s_cleaned.json`，277383467字节，作者LFS SHA-256 `d6f21ea9d60a0d56f34a05b609c79c88a451d2ae03597821ea3d5a9678c3a442`；dataset card标记MIT。原文件留在本地，不重新分发。
- 使用全部500题，一次固定协议评估；不先挑有利题目，不调参后把同一数据重新称为留出。oracle文件不参与检索评测。
- Runtime只接收问题文本、提问时间、会话ID/日期与role/content。`answer`、`answer_session_ids`、`has_answer`、题型和题目ID都不提供给检索器。题目ID的`_abs`后缀也不暴露给检索器。
- 会话为检索单位，以其日期及全部role/content构造文本，不由答案字段挑片段；每题只检索该题自己的历史。提问之后的会话先过滤，不能在检索之后再补救。原始日期按明确格式解析，未知格式立即失败，不跳过。
- 两个对照：按可用会话时间倒序；项目已有BM25（k1=1.2,b=.75，不调阈值）。同分按会话ID稳定排序。BM25只返回正分候选，最多5个会话；不调用模型或外部embedding服务。
- 输出非拒答题的session-recall@1/3/5、all-evidence-sessions-hit@1/3/5、MRR、各题型结果、上下文字符成本、时间。多证据题不能只用命中一个会话冒充完整覆盖。
- 拒答题单独报告nonempty retrieval率；它不是答案错误率。未运行生成模型或官方LLM judge，不报告LongMemEval回答准确率，不把BM25非零分当作可回答性证明。
- 会话级召回不证明具体答案段可见或答案正确，长会话可能超出产品上下文预算；明确报告返回字符数。没有把此通用对话benchmark当成真实欺诈调查或人工效率数据。

这一评测用于独立揭示当前检索的不足。产品欺诈审阅记忆优先使用主体/目标/时间结构过滤，当前小规模不需要语义向量库；公开对话检索指标不会冒充该业务路径的提升。
