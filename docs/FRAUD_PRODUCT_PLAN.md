# 主线纠偏：从检测告警到欺诈线索调查

2026-10-31。用户指出业务断层后重新规划。本文件优先于历史阶段的产品定位；历史实验及评分不改写。

## 产品选择与责任边界

RiskCase 是面向支付风险分析师的**事后批量欺诈告警调查工作台**。目标是把有限审核容量用在值得核查的告警上，为分析师提供可复核线索、反证和待补证据。当前只有研究原型，没有真实机构部署或收益验证。

流程为：交易 → 检测排序 → 日终审核名单 → 绑定同一交易/用户/截止时间的案件 → 证据核查 → 人工审阅与待办 → 外部确认结果（当前缺失）。检测分数不是欺诈事实；调查摘要不是新标签；批准内部调查工单不是资金处置。

第五阶段的重复扣款、退款到账与渠道宽限期属于支付差错/争议调查。退款完成不证明原交易获持卡人授权；没有退款不证明欺诈。这套实验只保留为文档取证和宿主控制测试，移出反欺诈主演示和效果指标。禁止凭 IBM 的负金额推造退款流水，禁止将匿名真实数据与合成用户拼成一案。

## 分阶段推进与验收

### 6A：业务接通与来源诚实（本轮完成，见STAGE6A_REPORT.md）

- 复用已有冻结神经模型的2018开发期日审核名单和无标签案件投影，接入相同 MCP 网关、Skill、Harness、待审阅工单；案件身份和分数可追溯回源记录。
- 工具只提供源内历史频次、金额基线、商户出现记录及明确标记的项目研究口径。设备、认证、客户确认、调查结案材料一律显示缺失，不能自建一封邮件当成真实业务证据。
- 核查全部3650条已有日审核记录的交易/用户/日期/排序合同，统计同用户同日重复占用容量；只报告描述统计，不未经验证自动合并、改变预算或宣传节省人时。
- 源案例通过真实 MCP 进程接入，停在待审阅；离线客户端明确是确定性接线基线，没有新模型能力成绩。
- 主入口展示欺诈告警；争议与经验实验单列。测试拒绝标签混入、跨用户、未来记录、分数身份错配、错误线索结论、将未发现线索判为安全。

### 6B：真实来源检测验证（尚未完成）

- 首选核验 IEEE-CIS/Vesta 官方竞赛数据及条款。官方说明来源为真实电商交易，适合外部检测研究；实际字段语义、实体是否可稳定关联、标签机制和可得时间必须先审计，不能假设已具备完整调查资料。
- 官方数据页/下载需能读取并符合使用条件；仅下载获准来源，不从来历不明镜像补齐。原始数据与标签留本地。
- 先冻结数据卡、时间切分、预处理拟合范围、特征可得性、预算与指标，再比较简单模型、强树和神经模型。已观察 IBM 2019 仅作回归。
- 以 PR-AUC、固定容量捕获率/误报、分时间段稳定性和运行成本衡量，不以准确率或模型新颖程度选择胜者。检测效果与 Agent 效果分别报告。
- 真实来源的匿名特征不能生成不存在的商户故事或人审原文；不能以真实检测集给合成调查实验背书。

### 6C：调查价值与真实任务验证（尚未完成）

- 获取有授权的、去标识的调查任务与反馈，或公开可验证案例；逐条登记来源和缺失，独立标注，先锁评测再开发。
- 比较确定性证据包、一次性模型分析、动态工具调查。在相同事实与权限下衡量证据准确率、遗漏、错误升级/错误关闭、人工修改量、审阅时间、调用成本与延迟。
- 只有复杂、证据不齐或问题多样的任务实测需要模型时才开启动态调查。RAG/记忆只有提供必要且可靠的知识时才能计入主线收益；不开启不适用的退款经验。
- 人工复核结论与已确认欺诈标签分开，保留标签确认时间与来源。没有外部结案就不训练“自进化”模型。

### 6D：运行规模与交付（尚未完成）

- 以告警/案件为单位测任务吞吐、积压、P95耗时、恢复率和审计完整性；百万交易离线统计不能替代调查服务压测。
- 检测队列容量从分析师预算推导；同用户聚案、超时与再次打开案件须明确口径，再测是否漏掉重要交易。
- 深度模型升级服务于检测瓶颈：先强树/现有残差基线，只有合法数据、时间可得性和对照支持才扩展序列/图方法。

## 数据证据边界

已核验 [IBM 官方仓库](https://github.com/IBM/TabFormer) 明确声明24M规模合成信用卡交易。上游大规模不等于本项目训练了全量，更不等于真实银行效果；现有冻结模型开发期422088条、最终2019期423189条，固定408用户。

[IEEE-CIS官方竞赛说明](https://www.kaggle.com/competitions/ieee-fraud-detection/overview/about-galaxy-zoo)描述 Vesta 真实电商来源；本次官网数据页没有返回可读字段/条款，**尚未取得和训练该数据**。ULB官方数据页面本次同样不可读，不以搜索摘要代替许可和字段审计。没有真实客户确认、认证日志或结案材料时，产品只能协助分析师核查线索。
