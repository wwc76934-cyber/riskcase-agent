# V3.1 离线四组对照运行器

运行器从带指纹的研究包读取单案，在相同的来源合同、阶段时钟和预算下，经本机 MCP 分别执行 B0、B1、B4、B2。控制器持有评分参考，工具子进程仅接收运行快照，模型上下文由已取得原件和工具回执组成。此入口仅接受脚本客户端。

汇总以 40 案、3 次重复、每案 3 阶段为每组计划分母。B0 单案结果在配对中复用，统计单位仍为案件。空缺或中断的条件保留在分母，区间只在对应条件和阶段完整时计算。可单独查看成功交付后的严格率、已覆盖事实准确率、引用支持和关键证据获取。

本机测试在一例自然语言案和一例预算分支案上各走完四条路径，并验证了重复结果拒绝、计划指纹校验与禁止外部客户端。全部是脚本协议验证。正式模型执行和受控记忆试验仍需要通过可靠性门槛及独立授权。
