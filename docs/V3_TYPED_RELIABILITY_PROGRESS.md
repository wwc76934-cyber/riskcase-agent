# V3：类型化交付与独立评测准备

## 当前结论

本阶段是修复与免费工程验收，不是Agent业务增益结论。旧90案、300条件及108个未接受主模型条件全部保留。第一批新开发预试也保留失败：36阶段仅19次交付，12条轨迹仅1条全部交付，56次真实模型请求，估算0.2044844元。T1/T2全样本10/24与成功交付后10/10分别报告，不能只报后者。

原始预试详见[V3_DELIVERY_PILOT_REPORT.md](V3_DELIVERY_PILOT_REPORT.md)。默认产品路径仍为B0。检测权重、特征工程、标签、2018/2019结果未修改。

## 从失败到修改

原预试17个失败阶段中，13个把程序正文写入长度受限的policy_version，2个把授权状态写成解释性段落，1个引用来源角色不符，1个把V事件编号放进F事实列表。新合同处理表示和引用负担，不替模型判断语义。

- 身份、目标支付和显示编号由宿主确定；模型只选择声明过的事实谓词、枚举值和本次原件行引用。每条观察限于单个原件；同一来源与谓词不得重复。
- 程序正文仍作为实际取得的上下文存在，不再要求抽取成版本号。宿主没有补齐未取得的关键事实。
- 每条客户观察按其到达时可用上下文解释；最终报告再处理后续纠正，不能倒改历史观察。认证成功仍不能替代支付意图。
- 终稿F、V编号分别绑定实际取得事实和事件。完整引文由宿主从已取得行复制，模型不能编造来源。
- 错误关闭或确认欺诈可以作为“不可信的模型建议”被记录并判为业务失败，宿主不会执行。不能把宿主安全约束冒充模型正确判断。

新合同尚无真实模型修复结果。脚本格式探针通过不等于语言理解正确。

## 三时点运行机制

新增代码保持在investigation/evaluation/service范围。每案一个租约，T0/T1/T2分别保存原件获取、模型响应、费用、阶段结果和恢复记录。模型API没有跨进程“恰好一次”保证；调用执行状态不明时停止并保留占用，不盲目重发。

本机MCP仅提供当前目录元数据和受限原件读取。时点推进属于宿主能力，评分参考不进入服务。来源按案件、主体、交易、时间、版本、哈希和依赖校验；不可变原件缓存不重复计费。宿主操作键与副作用在同一SQLite事务落盘，解决本地“读取已完成但计划尚未保存”的恢复窗口，不宣称外部银行服务恰好一次。

动态规划使用原生工具调用。模型看到当前可负担、依赖满足且未读取的来源，选择时记录目的与待检验假设；最多4次规划调用，另留2个交付槽位。请求日志与结果先落盘，恢复按已完成操作继续。原有共享JobStore的6次调用上限没有被放宽；新三阶段命名空间独立管理，付费授权仍须另行约束。

## 比较路径

| 路径 | 行为 | 需要验证的增量 |
| --- | --- | --- |
| B0 | 强确定性归因、否定、范围、纠正规则与预算内取证 | 便宜且可靠的默认路径 |
| B1 | 所有当前可取得资料，一次联合抽取和报告；仅对已知协议错误有界修复一次 | 强一次性LLM基线 |
| B1_staged | 相同资料权限，先观察、后终稿 | 把格式机制差异与动态规划分开 |
| B2 | 原生动态选资料、更新假设，再类型化交付 | 相对于强B1的取证质量或资源增量 |
| B4 | 确定性读取机器认证字段，LLM处理客户语义和冲突 | 不引入完整Agent是否已足够 |
| B3 | 目前禁止启动 | 稳定Agent基线后再研究记忆 |

B1与B4取得共同免费的当前资料及必要前置资料。在受预算限制场景中，用一次批量语义选择获取所有可负担资料；不隐藏本可获得的内容以制造B2优势。成本和时效都是作者模拟，不是实测银行费用或SLA。

B0仅在30个开发案运行：90/90阶段交付，68/90严格通过，13/30整条轨迹严格通过，15/30的T2目标说法正确。所有失败保留，40个评测候选没有评分。这个结果既不证明代码普遍失败，也不证明LLM会胜出。

## 数据与评分边界

候选v4指纹：`f8af041607e6f3c94c6f689f0f00f7db0f4ca18cf6876c73f3242fbd37a89329`。

v3到v4是同70案的参考修订：70/70原件字节相同，210/210主要目标说法标签相同，新增案例数0，旧结果重评分0。新的参考明确关键原件、条件性可知事实、反证和T2后仍可重开。全部标为作者模拟，尚未外部专家审查，尚未正式冻结。

评分分别记录获取不充分与“给定实际获取资料时”的理解错误；同时报全样本和交付后质量、按authentication/customer_authorization分开的事实正确率、结构引用支持、错误关闭和未证实欺诈建议。结构引用正确不是语义真值。认证字段在当前材料中均为success，必须作为覆盖限制披露，不能借其抬高语言理解表现。

40案人工评审包由本地`v3_human_review`生成。初始全部pending，未勾选人的身份与非创作声明。每案审阅绑定原件及参考哈希，需实际填写理由，修改或不确定阻止冻结。参考可见，属于参考审阅而非盲标注；身份与独立性来自审阅者自述，不能冒称核验过的专家。

正式对照提案需通过该评审后才可生成；提案本身不授权付费执行。预先注册案件、重复、条件、顺序、指标和指纹。主要比较B4−B0与B2−强B1，B2−B1_staged作为格式敏感性比较；不以打败较弱格式路径宣布Agent胜出。

案件为配对单位，重复运行不是新案件。区间按家族整体重采样，并重采样同案的预定配对重复；同时报告家族效果、病例加权结果和剔除单家族范围。少量作者家族不支持银行总体覆盖或显著性结论。聚类相关与少量聚类的限制参考[Cameron与Miller的原始论文](https://cameron.econ.ucdavis.edu/research/Cameron_Miller_JHR_2015_February.pdf)。若运行缺失或轨迹未完成，不从成功子集生成区间。
