# RiskCase Agent：V1范围与架构合同

更新：2026-10-22。[原规格](archive/RISK_PROJECT_SPEC.pre-final.md)保留发现过程；本页描述最终交付，结果见[结项报告](FINAL_REPORT.md)。目录名沿用financial-report-agent，仅为保留环境与路径，不表示年报项目。

## 用户与任务

用户是支付风险分析师。产品帮助其从预警查证历史、形成有引用的调查记录，评估一条规则在有限审核容量下是否值得继续研究。业务价值是可检验的假设；没有真实用户计时或真实资金收益证据。

输入：注册case、冻结模型/告警来源、截止时间、明确检查或自然语言问题、调用/时间/费用预算。输出：范围计划、证据与统计、资料缺口、轨迹、待审阅报告；规则研究另有版本化候选和回放材料。

## 最终模型与Agent分工

1. 特征代码从严格过去历史计算；神经模型预测。日top10是日终批量排序，不等于交易发生当时已知的实时排名。
2. 调查Agent不读标签。自然语言模型只读问题，无交易事实/文件/SQL/命令权限；给出待确认的检查集合。
3. 分析师明确确认范围后，宿主编译固定查询。窗口、分母、金额运算和判断由代码完成，报告绑定证据。
4. 报告进入单独审阅状态；接受报告不表示真实欺诈认定或规则发布。
5. 规则研究在2018开发数据进行。候选与纯模型按相同日容量比较，包含挤出损失。当前规则不支持采用，实际第2版保持待审阅。

ReAct工具循环和自由模型撰写分支仍可研究，但对照中未证明数值任务的查询/成本优势，因此不是默认的最终证据引擎。没有用关键词离线演示冒充真实模型Agent成绩。

## 研究验收口径

检测主口径TP@每天10笔，辅以P/R/AP及5/20预算；训练2016–2017、开发2018，模型、预处理、代码、名单、协议冻结后最终2019一次性评测。主模型是预先声明的3seed均值，不因seed42最终更高就替换。最终结果保留强树对照和不确定区间。

Agent范围按决策和完整检查集合全对才通过，100题分母包含失败；首次/纠正后分别统计。独立题由另一助手在未看新提示时编写，不是专家样本或真实用户流量。数字SQL正确与语义范围正确分别计分。

模型分数敏感性只表示改变单输入的分数变化，不是因果、可实现反事实或已校准概率。数据/模型哈希与行序重算对齐后才能把预警和解释配对。

## 非目标和交付边界

不自动冻结/付款/拒付、不认定违法、不提供真实银行概率评级。无生产用户画像、真实设备关联或反洗钱身份数据，不编造图关系训练GNN。无经过评测的文档RAG/长期记忆/MCP接入，不写成已实现。

V1交付本地研究系统、代码、测试、固定源内结果、冷启动演示、合成源模型整合包、图表、来源说明和面试材料。真实业务外部验证、企业身份/生产部署与公开发布权利另需证据，不能由当前研究结项自动推导。
